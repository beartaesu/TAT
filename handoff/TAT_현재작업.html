TAT 현재 작업

갱신일: 2026-09-03
현재 작업: 현장 자동 추가를 위한 최소 열 2개 생성
이번 단계: 기존 현장마스터에 열만 추가
별도 업체마스터는 만들지 않습니다. 기존 현장마스터는 앱이 자동으로 기본 현장과 사용자 현장을 저장하고, 다음 접수에서 다시 보여주기 위한 내부 목록으로만 사용합니다. 사용자가 현장 행을 미리 일일이 만들 필요는 없습니다.

1. 기존 현장마스터 열 추가

  1. SharePoint → 현장마스터 목록을 엽니다.
  2. 열 추가를 눌러 아래 두 열만 만듭니다.
열 이름형식설정
업체명복사 한 줄 텍스트 필수 아니요, 고유 값 적용 아니요, 기본값 없음
기본현장여부 예/아니요 기본값 아니요

이번에는 하지 않는 것

  • 업체마스터 목록 생성하지 않음
  • 업체연결 Lookup 생성하지 않음
  • 업체ID복사 숫자 열 생성하지 않음
  • 인덱스 생성하지 않음
  • 기존 현장마스터 행 수정하지 않음
  • Power Apps·Power Automate 수정 또는 실행하지 않음

완료 후 알려줄 내용

  • 업체명복사 생성 완료 / 오류
  • 기본현장여부 생성 완료 / 오류
  • 동일한 이름의 기존 열이 있었다면 그 열의 현재 형식
업체나 현장 데이터 행은 아직 입력하지 마세요.
