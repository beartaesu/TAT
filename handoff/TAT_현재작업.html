TAT 현재 작업

갱신일: 2026-09-03
현재 작업: 접수 기본정보 행2에 업체 선택 영역 추가
이번 단계: 업체 후보 표시만 검증, 현장 필터·자동 생성은 아직 연결하지 않음
기존 cmb현장과 txt계산서업체는 변경하지 않습니다. 먼저 업체 선택 영역만 추가해 기존 현장 행이 업체 후보로 정상 표시되는지 확인합니다.

정확한 추가 위치와 트리

scr접수기본정보
> con접수기본전체
> con접수기본본문
> con접수기본카드
> con접수기본행2

완료 후 자식 순서는 아래와 같아야 합니다.

con접수기본행2
├─ con업체영역
│  ├─ lbl업체
│  └─ cmb업체
├─ con현장영역
│  ├─ lbl현장
│  └─ cmb현장
└─ con계산서업체영역
   ├─ lbl계산서업체
   └─ txt계산서업체

1. 기존 영역 복제·이름 변경

  1. 트리에서 con현장영역을 선택해 복사한 뒤 con접수기본행2 안에 붙여넣습니다.
  2. 복제된 컨테이너 이름을 con업체영역으로 변경합니다.
  3. 복제된 자식 레이블 이름을 lbl업체로 변경합니다.
  4. 복제된 자식 콤보박스 이름을 cmb업체로 변경합니다.
  5. 트리에서 con업체영역을 con현장영역 바로 위로 이동합니다.

2. lbl업체 전체 속성

Text

"업체"

3. cmb업체 전체 속성

Items

SortByColumns(
    Filter(
        현장마스터,
        기본현장여부 = true ||
        IsBlank(업체명복사)
    ),
    "Title",
    SortOrder.Ascending
)

DefaultSelectedItems

If(
    var완료접수수정모드 || var이어쓰기,
    With(
        {
            loc현재현장: LookUp(
                현장마스터,
                ID = var저장헤더.'업체/현장'.Id
            )
        },
        If(
            IsBlank(loc현재현장),
            Blank(),
            [
                If(
                    IsBlank(loc현재현장.업체명복사),
                    loc현재현장,
                    With(
                        {
                            loc기본현장: LookUp(
                                현장마스터,
                                업체명복사 = loc현재현장.업체명복사 &&
                                기본현장여부 = true
                            )
                        },
                        If(
                            IsBlank(loc기본현장),
                            loc현재현장,
                            loc기본현장
                        )
                    )
                )
            ]
        )
    ),
    Blank()
)

4. 저장 후 이번 단계 검증

  • 빨간 수식 오류가 없는지 확인합니다.
  • 행2에 업체·현장·계산서 업체 세 영역이 겹치지 않고 표시되는지 확인합니다.
  • 신규 입력 상태에서 cmb업체를 열면 기존 현장마스터 행들이 업체 후보로 표시되는지 확인합니다.
  • 기존 cmb현장에서 현장을 선택하면 txt계산서업체가 이전처럼 표시되는지 확인합니다.
  • 수정 또는 이어쓰기 화면에서 저장된 현장이 업체 기본 선택으로 표시되는지 확인합니다.

알려줄 결과

  • 수식 오류: 없음 / 있음
  • 행2 배치: 정상 / 겹침
  • 업체 후보: 표시됨 / 0건 / 중복 이상
  • 기존 현장 선택 후 계산서 업체 표시: 정상 / 비정상
  • 수정·이어쓰기 업체 기본 선택: 정상 / 미확인 / 비정상
