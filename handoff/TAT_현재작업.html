TAT 현재작업 — 실제 현장 저장 연결

아래 6개 속성을 순서대로 전체 교체합니다. 이번 검증은 현장마스터에 시험 현장 한 건을 만들 수 있으므로, 실제로 추가해도 되는 현장명으로 시험하세요. btn최종저장은 아직 누르지 않습니다.

1. cmb업체.Items

위치: scr접수기본정보 > con접수기본전체 > con접수기본본문 > con접수기본카드 > con접수기본행2 > con업체영역 > cmb업체

SortByColumns(
    Filter(
        현장마스터,
        기본현장여부 = true ||
        업체명복사 = Blank()
    ),
    "Title",
    SortOrder.Ascending
)

기존 레거시 행은 업체명복사가 비어 있어 계속 업체 후보로 보이고, 이후 생성되는 사용자 현장은 기본현장여부 = false이므로 업체 후보에서 제외됩니다.

2. cmb업체.OnChange

Set(var신규현장ID, Blank());
Reset(cmb현장)

3. cmb현장.Items

위치: con현장영역 > con현장입력행 > cmb현장

If(
    IsBlank(cmb업체.Selected),
    Filter(
        현장마스터,
        ID = -1
    ),
    With(
        {
            loc업체명:
                Coalesce(
                    cmb업체.Selected.업체명복사,
                    cmb업체.Selected.제목
                )
        },
        Filter(
            현장마스터,
            ID = cmb업체.Selected.ID ||
            업체명복사 = loc업체명
        )
    )
)

4. cmb현장.DefaultSelectedItems

If(
    !IsBlank(var신규현장ID),
    [
        LookUp(
            현장마스터,
            ID = var신규현장ID
        )
    ],
    If(
        var완료접수수정모드 || var이어쓰기,
        [
            LookUp(
                현장마스터,
                ID = var저장헤더.'업체/현장'.Id
            )
        ],
        If(
            IsBlank(cmb업체.Selected),
            Blank(),
            [cmb업체.Selected]
        )
    )
)

5. btn현장추가저장.DisplayMode

위치: scr접수기본정보 > con현장추가패널 > con현장추가카드 > con현장추가버튼행 > btn현장추가저장

If(
    IsBlank(cmb업체.Selected) ||
    IsBlank(Trim(txt현장추가명.Text)),
    DisplayMode.Disabled,
    DisplayMode.Edit
)

6. btn현장추가저장.OnSelect

With(
    {
        loc업체명:
            Coalesce(
                cmb업체.Selected.업체명복사,
                cmb업체.Selected.제목
            ),
        loc현장명:
            Trim(txt현장추가명.Text)
    },
    Set(var현장저장성공, false);
    Set(var신규현장ID, Blank());

    IfError(
        Patch(
            현장마스터,
            cmb업체.Selected,
            {
                업체명복사: loc업체명,
                기본현장여부: true
            }
        );

        Refresh(현장마스터);

        ClearCollect(
            col동일업체현장,
            FirstN(
                Filter(
                    현장마스터,
                    업체명복사 = loc업체명 &&
                    제목 = loc현장명
                ),
                2
            )
        );

        If(
            CountRows(col동일업체현장) > 1,
            Notify(
                "같은 업체에 동일한 현장명이 2건 이상 있습니다. 현장마스터를 확인해 주세요.",
                NotificationType.Error
            ),

            CountRows(col동일업체현장) = 1,
            Set(
                var신규현장ID,
                First(col동일업체현장).ID
            );
            Set(var현장저장성공, true),

            Set(
                var신규현장ID,
                Patch(
                    현장마스터,
                    Defaults(현장마스터),
                    {
                        제목: loc현장명,
                        업체명복사: loc업체명,
                        기본현장여부: false,
                        '계산서 업체 연결':
                            cmb업체.Selected.'계산서 업체 연결'
                    }
                ).ID
            );
            Set(var현장저장성공, true)
        ),

        Notify(
            "현장 저장 중 오류가 발생했습니다: " &
            FirstError.Message,
            NotificationType.Error
        )
    );

    If(
        var현장저장성공,
        Refresh(현장마스터);
        Reset(cmb현장);
        Reset(txt현장추가명);
        Set(var현장추가패널, false);
        Notify(
            "현장이 선택되었습니다.",
            NotificationType.Success
        )
    )
)

7. 적용 직후 먼저 확인

  1. 빨간 수식 오류가 없는지 확인합니다.
  2. cmb업체.Items와 cmb현장.Items에 위임 경고가 생겼는지 확인합니다.
  3. 오류 또는 위임 경고가 있으면 아직 저장 버튼을 누르지 말고, 발생한 정확한 속성을 알려주세요.

8. 오류·경고가 없을 때 실제 검증

  1. 업체를 선택하면 기존처럼 업체명과 같은 기본 현장이 자동 선택된다.
  2. 현장 추가 팝업을 열고 해당 업체에 실제로 추가해도 되는 새 현장명을 입력해 저장한다.
  3. 성공 알림 후 팝업이 닫히고 새 현장이 cmb현장에 자동 선택된다.
  4. 계산서 업체가 선택 업체의 기존 연결값으로 표시된다.
  5. SharePoint 현장마스터에서 선택 업체 기본 행은 업체명복사 = 업체명, 기본현장여부 = 예로 보정된다.
  6. 새 현장 행은 입력한 제목, 같은 업체명복사, 기본현장여부 = 아니요, 같은 계산서 업체 연결값으로 생성된다.
  7. 같은 현장명을 다시 저장하면 새 행을 중복 생성하지 않고 기존 현장을 선택한다.
  8. 업체 콤보박스를 다시 열었을 때 사용자 추가 현장이 업체 후보로 나타나지 않는다.
  9. btn접수기본다음으로 다음 화면 이동까지 정상인지 확인한다. btn최종저장은 아직 누르지 않는다.

위 결과를 알려주세요. 성공하면 마지막으로 btn최종저장.OnSelect의 구형 현장 참조 8곳을 전체 수식으로 교체합니다.
