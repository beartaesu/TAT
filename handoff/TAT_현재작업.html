TAT 현재작업 — TAT-06 btn현장추가저장.OnSelect 전체 교체

이번 단계에서는 실제 현장을 생성하지 않습니다.
전체 수식을 교체하고 앱을 저장한 뒤 오류·위임 경고만 확인합니다. 현장 추가 저장 버튼은 아직 누르지 않습니다.

정확한 위치

scr접수기본정보의 현장 추가 팝업 안 btn현장추가저장 > OnSelect

OnSelect 전체 교체 수식

With(
    {
        loc업체명: Trim(Text(cmb업체.Selected.제목)),
        loc현장명: Trim(txt현장추가명.Text),
        loc계산서업체ID: cmb업체.Selected.기본계산서업체.Id,
        loc계산서업체명: cmb업체.Selected.기본계산서업체.Value
    },
    If(
        IsBlank(cmb업체.Selected) || IsBlank(loc업체명),
        Notify(
            "업체를 먼저 선택해 주세요.",
            NotificationType.Error
        ),
        IsBlank(loc현장명),
        Notify(
            "현장명을 입력해 주세요.",
            NotificationType.Error
        ),
        IsBlank(loc계산서업체ID),
        Notify(
            "선택한 업체에 기본 계산서 업체가 연결되어 있지 않습니다. 업체마스터를 확인해 주세요.",
            NotificationType.Error
        ),
        Set(var현장저장성공, false);
        Set(var신규현장ID, 0);

        ClearCollect(
            col동일업체현장,
            FirstN(
                Filter(
                    현장마스터,
                    업체명복사 = loc업체명 &&
                    제목 = loc현장명
                ),
                2
            )
        );

        If(
            CountRows(col동일업체현장) > 1,
            Notify(
                "같은 업체에 동일한 현장명이 2건 이상 있습니다. 현장마스터를 확인해 주세요.",
                NotificationType.Error
            ),
            CountRows(col동일업체현장) = 1,
            Set(
                var신규현장ID,
                First(col동일업체현장).ID
            );
            Set(var현장저장성공, true),
            IfError(
                Set(
                    var신규현장ID,
                    Patch(
                        현장마스터,
                        Defaults(현장마스터),
                        {
                            제목: loc현장명,
                            업체명복사: loc업체명,
                            기본현장여부: false,
                            '계산서 업체 연결': {
                                Id: loc계산서업체ID,
                                Value: loc계산서업체명
                            }
                        }
                    ).ID
                );
                Set(var현장저장성공, true),
                Notify(
                    "현장 저장 중 오류가 발생했습니다: " & FirstError.Message,
                    NotificationType.Error
                )
            )
        );

        If(
            var현장저장성공,
            Refresh(현장마스터);
            Reset(cmb현장);
            Reset(txt현장추가명);
            Set(var현장추가패널, false);
            Notify(
                "현장이 선택되었습니다.",
                NotificationType.Success
            )
        )
    )
)

저장 후 확인

  1. OnSelect 기존 수식 전체를 위 수식으로 교체합니다.
  2. 앱을 저장합니다.
  3. 해당 속성과 앱 검사에서 빨간 수식 오류가 없는지 확인합니다.
  4. 위임 경고가 없는지 확인합니다.
  5. 현장 추가 저장 버튼은 누르지 않습니다.
  6. SharePoint 현장마스터 건수가 변경되지 않았는지 확인합니다.

회신할 내용: 수식 적용·저장 성공 여부, 빨간 오류·위임 경고 유무, 현장 추가 미실행 및 현장마스터 건수 유지 여부만 알려주세요.
