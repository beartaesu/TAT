TAT 현재작업 — TAT-04B 정상 후보 27개 안전 적재

이번 단계에서 처음으로 SharePoint 업체마스터에 27개 항목을 생성합니다.
반드시 복사본 TAT_업체마스터_안전적재만 수정합니다. 안전 게이트와 업체별 중복 확인을 모두 구성하고 저장한 뒤 한 번만 실행합니다. 일부만 생성되거나 실패하면 임의 삭제·재실행하지 말고 결과 건수만 보고합니다.

확인된 실행 전 기준

  • 계산서마스터분류합계검증 = true
  • 업체마스터사전건수 = 0
  • var계산서마스터정상후보 길이 = 27
  • 미일치 134개·1:N 2개·공란 1개는 이번 생성 대상에서 제외

1. 생성 건수 변수 초기화

업체마스터사전건수 바로 아래 최상위 단계에 변수 초기화를 추가합니다.

  • 작업 표시 이름: 업체마스터생성건수초기화
  • Name: var업체마스터생성건수
  • Type: Integer
  • Value: 숫자 0

2. 쓰기 전 안전 게이트

변수 초기화 바로 아래에 조건을 추가하고 이름을 업체마스터안전적재조건으로 바꿉니다. 고급식 또는 조건 전체 fx에 아래 표현식을 사용합니다.

and(
  equals(outputs('계산서마스터분류합계검증'), true),
  equals(length(body('업체마스터사전조회')?['value']), 0),
  equals(length(variables('var계산서마스터정상후보')), 27)
)

이 조건의 True 안에서만 다음 3~5번 작업을 만듭니다.

False 분기: 컨트롤의 종료(Terminate)를 추가합니다.

  • 이름: 업체마스터안전적재차단
  • 상태: 실패(Failed)
  • 코드: TAT04_GATE_BLOCKED
  • 메시지: 분류검증, 업체마스터 공란, 정상후보 27개 중 하나 이상이 일치하지 않아 적재를 차단했습니다.

3. True 안에 정상 후보 반복 추가

각각에 적용(Apply to each)을 추가하고 이름을 업체마스터안전후보반복으로 바꿉니다.

반복 입력의 fx 식:

variables('var계산서마스터정상후보')

동시성 제어는 켜지 않고 기본 순차 실행으로 둡니다.

4. 반복 안에서 같은 업체 제목 재확인

업체마스터안전후보반복 안에 SharePoint 2개 이상의 항목 가져오기(Get items)를 추가하고 이름을 업체마스터업체중복조회로 바꿉니다.

  • 사이트 주소: 현재 TAT SharePoint 사이트
  • 목록 이름: 업체마스터
  • 필터 쿼리: 아래 fx 식 전체
  • 위쪽 개수: 2
concat(
  'Title eq ''',
  replace(
    items('업체마스터안전후보반복')?['업체명'],
    '''',
    ''''''
  ),
  ''''
)

조회 아래에 조건을 추가하고 이름을 업체마스터업체미존재조건으로 바꿉니다.

  • 왼쪽 fx: length(body('업체마스터업체중복조회')?['value'])
  • 연산자: 다음과 같음
  • 오른쪽 숫자: 0

5. 미존재 True에서 업체 생성

업체마스터업체미존재조건의 True에 SharePoint 항목 만들기(Create item)를 추가하고 이름을 업체마스터생성으로 바꿉니다.

업체마스터 입력 필드입력값
제목fx items('업체마스터안전후보반복')?['업체명']
기본계산서업체 Idfx int(items('업체마스터안전후보반복')?['계산서업체ID'])
사용여부예 또는 Boolean true

Power Automate에 Lookup 필드가 기본계산서업체 Id로 표시되는 항목을 사용합니다. 이름이 다른 필드를 추측해 선택하지 않습니다.

업체마스터생성 바로 아래 같은 True 분기에 변수 증가(Increment variable)를 추가합니다.

  • Name: var업체마스터생성건수
  • Value: 숫자 1

업체마스터업체미존재조건의 False: 작성(Compose)을 추가합니다.

  • 이름: 업체마스터중복차단
  • 입력 고정 문구: 같은 업체 제목이 이미 존재하여 이 항목은 생성하지 않았습니다.

예상치 못한 중복이 있으면 해당 항목만 생성되지 않아 최종 생성 검증이 false가 됩니다. 이 경우 임의 삭제·재실행하지 않습니다.

6. 반복이 끝난 뒤 사후 건수와 최종 검증

업체마스터안전후보반복이 끝난 아래쪽, 안전 게이트 True 분기 안에 SharePoint 2개 이상의 항목 가져오기를 추가합니다.

  • 이름: 업체마스터사후조회
  • 목록: 업체마스터
  • 위쪽 개수: 100
  • 필터·정렬: 비움

작성(Compose) 세 개를 순서대로 추가합니다.

작업 이름입력 fx 식
업체마스터생성건수variables('var업체마스터생성건수')
업체마스터사후건수length(body('업체마스터사후조회')?['value'])
업체마스터생성검증and(equals(variables('var업체마스터생성건수'), 27), equals(length(body('업체마스터사후조회')?['value']), 27))

7. 저장 후 한 번만 실행

  1. 전체 구조를 저장합니다. 저장 오류가 있으면 실행하지 않습니다.
  2. Flow를 수동으로 한 번만 실행합니다.
  3. 성공 시 생성 건수 27, 사후 건수 27, 생성 검증 true인지 확인합니다.
  4. SharePoint 업체마스터에서 중복 업체가 없고 기본계산서업체 Lookup과 사용여부가 채워졌는지 표본 몇 건만 회사 PC에서 확인합니다.
  5. 실제 업체명·계산서 업체명·ID는 대화나 MYBOX에 올리지 않습니다.
  6. 실패·부분 생성 시 업체마스터 항목을 삭제하거나 Flow를 재실행하지 말고, 성공/실패 작업명과 생성·사후 건수만 보고합니다.

회신할 내용: Flow 성공 여부, 업체마스터 생성 건수, 사후 건수, 생성 검증값, 중복 없음 여부, Lookup·사용여부 표본 정상 여부만 알려주세요.
