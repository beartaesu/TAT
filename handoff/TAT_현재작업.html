현재 작업: 접수 선택 조회 부분 검증 기록
상태: 기본 UI 확인·실데이터 검증 대기(완전 검증 아님)
중요 기록: 업체 표시·선택과 패널 열기, 금액 표시는 확인했지만 로우데이터가 없어 업체별 제외·정산확정 외 제외·실제 금액 정확성은 검증하지 못했습니다. 이 기능을 100% 완료로 간주하지 않습니다.

실제 데이터 이관 후 재검증 목록

  • 다른 계산서 업체의 접수가 섞이지 않는지
  • 정산확정 외 상태의 접수가 섞이지 않는지
  • 공급가액합계 실제 값과 화면 금액이 일치하는지
  • 빈 금액은 `금액 미이관`, 실제 0원은 0원으로 구분되는지
  • 업체별 외부 담당자가 정확히 매칭되는지
  • 대규모 데이터에서 위임으로 인한 누락이 없는지
잔여 항목: 계산서 업체 콤보박스의 원인 미확정 노란 경고와 접수 갤러리의 Lookup 위임 경고. 실제 배정 저장을 운영 완료로 처리하기 전에 다시 확인합니다.

지금 할 작업 — 수식 변경 없음

계산서 업체 콤보박스의 잔여 노란 경고는 후순위로 보류합니다. 이번에는 아래 기능만 순서대로 확인합니다.
  1. `새로 만들기`를 누릅니다.
  2. `계산서 업체`에서 실제 업체 하나를 선택합니다.
  3. `외부 담당자` 목록에 그 업체의 사용 중 세금계산서 담당자가 표시되는지 확인합니다.
  4. `접수 추가` 버튼이 활성화되는지 확인하고 클릭합니다.
  5. 팝업에 해당 업체의 `정산확정` 접수만 표시되는지 확인합니다.
  6. 공급가액이 비어 있는 접수에 `금액 미이관`이 표시되는지 확인합니다.
계산서 업체 콤보박스의 잔여 경고와 접수 갤러리의 위임 경고는 서로 다른 항목입니다. 지금은 기능 결과를 확인하되, 실제 배정 저장은 아직 진행하지 않습니다.
1차 교정 결과: 표시명 ["제목"]을 입력하면 Power Apps가 다시 ["ComplianceAssetId"]로 자동 변경했습니다. 문자열 필드 배열에는 SharePoint 기본 제목 열의 내부 이름 Title을 사용합니다.
