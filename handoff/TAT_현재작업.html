TAT 현재작업 — TAT-06A 실제 현장 1건 최초 생성

이번 단계에서 SharePoint 현장마스터에 실제 항목 1건을 생성합니다.
실제로 필요한 현장 하나만 사용하고 저장 버튼은 한 번만 누릅니다. 실패하거나 일부만 반영되면 삭제·수정하거나 다시 누르지 않습니다.

실행 전 기준

  • btn현장추가저장.OnSelect 전체 수식 적용·저장 완료
  • 빨간 수식 오류 없음
  • 위임 경고 없음
  • 선택할 업체의 기본계산서업체 Lookup 연결 완료

1. 실제 필요한 신규 현장 선택

  1. scr접수기본정보에서 업체마스터의 기존 업체 한 곳을 선택합니다.
  2. 현장 목록에 해당 업체의 현장이 아직 없는지 확인합니다.
  3. 현장 추가 패널을 열고 실제 필요한 현장명을 입력합니다.
  4. 실제 업체명과 현장명은 대화나 MYBOX에 기록하지 않습니다.

2. 저장 버튼 한 번 실행

  1. btn현장추가저장을 한 번만 누릅니다.
  2. 현장이 선택되었습니다. 성공 알림이 표시되는지 확인합니다.
  3. 패널이 닫히고 생성된 현장이 cmb현장에 자동 선택되는지 확인합니다.
  4. txt계산서업체에 선택 업체의 기본 계산서업체가 표시되는지 확인합니다.

3. SharePoint 직접 확인

현장마스터에서 방금 생성된 한 행을 확인합니다.

  • 제목: 입력한 현장명
  • 업체명복사: 선택한 업체명
  • 기본현장여부: 아니요
  • 계산서 업체 연결: 선택 업체의 기본계산서업체 Lookup
  • 전체 건수: 실행 전보다 정확히 1건 증가
실패·부분 생성 시: 같은 버튼을 다시 누르거나 생성 행을 삭제·수정하지 않습니다. 오류 문구, 성공 알림 여부, 현장마스터 증가 건수만 알려주세요.

회신할 내용: 성공 알림, 자동 선택, 계산서업체 표시, 현장마스터 1건 증가, 제목·업체명복사·기본현장여부·계산서 업체 연결 정상 여부만 알려주세요.
