TAT 현재 작업

갱신일: 2026-09-02
Git 기준: main / 148418a
현재 작업: foreach 내부 Terminate 저장 오류 교정
이번 단계: 트리 교정·저장만 하고 실행 금지

확정 원인

오류 InvalidWorkflowRunAction은 시험이관실패종료(Terminate)가 시험상세행반복(foreach) 내부에 중첩되어 발생했습니다. Code 입력이 원인이 아닙니다. 이번 교정에서는 Terminate와 Code를 사용하지 않습니다.

최종 정상 트리

시험이관가능조건
├─ True
│  ├─ 시험접수헤더생성
│  ├─ 시험상세행반복                      [각각에 적용]
│  │  ├─ 반복_시료명존재조건
│  │  ├─ 상세반복_분석항목조회
│  │  ├─ 상세반복_접수항목상세생성
│  │  └─ 상세반복_생성건수증가
│  ├─ 시험생성상세건수                    [작성 / 반복 바깥]
│  └─ 시험생성건수검증조건                [조건 / 반복 바깥]
│     ├─ True
│     │  └─ 시험이관완료요약              [작성]
│     └─ False
│        └─ 시험이관실패요약              [작성]
└─ False: 작업 없음

1. 반복 내부의 잘못된 사후검증 삭제

  1. 시험상세행반복을 펼칩니다.
  2. 반복 안에는 아래 네 작업만 남겨야 합니다.
    • 반복_시료명존재조건
    • 상세반복_분석항목조회
    • 상세반복_접수항목상세생성
    • 상세반복_생성건수증가
  3. 반복 안에 들어간 시험생성상세건수와 시험생성건수검증조건을 삭제합니다. 조건을 삭제하면 그 안의 완료·실패 작업도 함께 삭제됩니다.

2. 시험생성상세건수를 반복 바깥에 다시 추가

  1. 시험상세행반복 전체 카드의 아래쪽 +를 누릅니다. 반복 카드 내부의 +가 아닙니다.
  2. 위치는 시험이관가능조건의 True 안이면서 시험상세행반복과 같은 들여쓰기여야 합니다.
  3. 데이터 작업 → 작성, 이름: 시험생성상세건수
  4. 입력의 식: variables('var시험생성상세건수')

3. 검증 조건을 반복 바깥에 다시 추가

  1. 시험생성상세건수 바로 아래에 제어 → 조건을 추가합니다.
  2. 이름: 시험생성건수검증조건
  3. 왼쪽: 시험생성상세건수의 출력 동적 콘텐츠
  4. 연산자: 같음
  5. 오른쪽 식: int(outputs('시험접수행수'))

4. True에 완료 요약 작성

  1. 검증 조건의 True 안에 데이터 작업 → 작성을 추가합니다.
  2. 이름: 시험이관완료요약
  3. 입력의 전체 식:
concat(
  '접수번호=',
  string(outputs('시험접수번호확인')),
  ' / 헤더ID=',
  string(body('시험접수헤더생성')?['ID']),
  ' / 상세생성=',
  string(outputs('시험생성상세건수')),
  '건'
)

5. False에는 Terminate 대신 실패 요약 작성

  1. 검증 조건의 False 안에 데이터 작업 → 작성을 추가합니다.
  2. 이름: 시험이관실패요약
  3. Code 입력란과 종료 작업은 사용하지 않습니다.
  4. 입력의 전체 식:
concat(
  '원천 행 수 ',
  string(outputs('시험접수행수')),
  '건과 상세 생성 성공 ',
  string(outputs('시험생성상세건수')),
  '건이 일치하지 않습니다. 헤더 ID=',
  string(body('시험접수헤더생성')?['ID'])
)

6. 저장 확인

  • 시험상세행반복 안에는 네 작업만 있는지
  • 시험생성상세건수와 검증 조건이 반복 카드와 같은 들여쓰기인지
  • False가 시험이관실패요약 작성인지
  • Flow 저장이 성공하는지
이번에는 저장 성공만 확인하고 아직 실행하지 마세요.
