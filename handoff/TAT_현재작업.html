원천 업체명에서 Lookup용 현장마스터 ID까지의 연결을 검증했습니다. 이제 계산서 업체명을 읽습니다.

회사 PC에서 할 작업

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집
추가 위치: 기존 시험현장ID확인 작업 바로 아래의 +

완성할 Flow 트리

Power Automate
└─ 내 흐름
   └─ TAT_이관_시험조회 (편집)
      ├─ 수동으로 흐름 트리거
      ├─ 시험접수번호확인          [데이터 작업 - 작성]
      ├─ 테이블에 있는 행 나열     [Excel Online (Business)]
      ├─ 시험접수행필터             [데이터 작업 - 배열 필터링]
      ├─ 시험접수행수               [데이터 작업 - 작성]
      ├─ 기존접수조회               [SharePoint - 2개 이상의 항목 가져오기]
      ├─ 기존접수건수               [데이터 작업 - 작성]
      ├─ 시험업체명확인             [데이터 작업 - 작성]
      ├─ 시험현장조회               [SharePoint - 2개 이상의 항목 가져오기]
      ├─ 시험현장건수               [데이터 작업 - 작성]
      ├─ 시험현장ID확인             [데이터 작업 - 작성]
      └─ 시험계산서업체명확인       [데이터 작업 - 작성] ← 지금 추가

정확한 추가 순서

  1. 시험현장ID확인 바로 아래의 +를 누르고 작업 추가를 선택합니다.
  2. 데이터 작업 → 작성을 선택합니다.
  3. 새 작성 작업의 이름을 시험계산서업체명확인으로 바꿉니다.
  4. 입력에서 식을 선택해 아래 전체 식을 입력합니다.
    first(body('시험접수행필터'))?['계산서 업체']
  5. Flow를 저장하고 앞에서 사용한 같은 시험값으로 수동 실행합니다.

알려줄 결과

  • 시험계산서업체명확인 입력·출력이 공란이 아닌지
  • Flow 전체 성공 여부

Power Apps 화면이나 컨트롤 트리에는 아무것도 추가하지 않습니다.
