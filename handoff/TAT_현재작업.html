시험의뢰구분판정이 접수번호에 맞는 값으로 정상 출력됐습니다.
시험의뢰구분유효확인 입력·출력은 true입니다.

회사 PC에서 할 작업

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집
추가 위치: 변수 2개는 분석항목불일치건수초기화 아래·시험분석항목반복 위, 반복 계산은 기존 반복 안의 마지막

1. 최상위 변수 2개 추가

  1. 분석항목불일치건수초기화 아래, 시험분석항목반복 위의 +에서 변수 → 변수 초기화를 추가합니다.
  2. 작업 이름: 시료수최댓값초기화, 변수 이름: var시험시료수최댓값, 형식: 정수, 값: 0
  3. 그 바로 아래에 변수 → 변수 초기화를 하나 더 추가합니다.
  4. 작업 이름: 공급가액합계초기화, 변수 이름: var시험공급가액합계, 형식: 부동 소수점 수, 값: 0

2. 기존 반복 안에 시료수 최댓값 갱신 추가

  1. 시험분석항목반복 안의 기존 반복_분석항목불일치조건 전체 아래, 같은 반복 수준에 제어 → 조건을 추가합니다.
  2. 작업 이름: 반복_시료수최댓값갱신조건
  3. 왼쪽 식: int(items('시험분석항목반복')?['수량'])
  4. 연산자: 다음보다 큼, 오른쪽 식: variables('var시험시료수최댓값')
  5. Yes 안에 변수 → 변수 설정을 추가합니다. 작업 이름: 반복_시료수최댓값설정
  6. 변수: var시험시료수최댓값, 값의 식: int(items('시험분석항목반복')?['수량'])
  7. No는 비워 둡니다.

3. 기존 반복 안에 공급가액 누적 추가

  1. 반복_시료수최댓값갱신조건 전체 아래, 같은 반복 수준에 변수 → 변수 증가를 추가합니다.
  2. 작업 이름: 반복_공급가액합계증가
  3. 변수: var시험공급가액합계
  4. 값의 식:
    if(empty(items('시험분석항목반복')?['공급가액']), 0, float(items('시험분석항목반복')?['공급가액']))

4. 반복 아래 최상위에 작성 4개 추가

  1. 기존 시험의뢰구분유효확인 바로 아래에 데이터 작업 → 작성 4개를 순서대로 추가합니다.
  2. 시험시료수확인 — variables('var시험시료수최댓값')
  3. 시험공급가액합계확인 — variables('var시험공급가액합계')
  4. 시험총금액확인 — float(first(body('시험접수행필터'))?['총금액'])
  5. 시험금액일치확인 — equals(float(outputs('시험공급가액합계확인')), float(outputs('시험총금액확인')))
  6. Flow를 저장하고 같은 시험값으로 한 번 실행합니다.
