TAT 현재작업 — TAT-04B 안전적재 Flow 반복 참조 교정·저장

이번 단계에서는 Flow를 실행하지 않습니다.
반복 참조를 교정한 뒤 저장 성공만 확인합니다. 실행하면 최초로 SharePoint 업체마스터 쓰기가 발생할 수 있으므로 실행은 다음 확인 전까지 금지합니다.

확정된 안전 기준

  • 9월 8일 최종 데이터 행은 tblTATMigration 내부
  • 최신 계산서마스터 정상후보: 27개
  • SharePoint 업체마스터 사전 건수: 0개

1. 반복 안쪽 구조 확인

  1. TAT_업체마스터_안전적재를 편집합니다.
  2. 업체마스터업체중복조회와 업체마스터생성이 모두 업체마스터안전후보반복 안쪽에 있는지 확인합니다.
  3. 두 작업이 반복 바깥에 있으면 반복 안쪽으로 옮긴 뒤 아래 식을 적용합니다.

2. 업체마스터업체중복조회 필터 쿼리 전체 교체

필터 쿼리의 기존 식 전체를 다음 식으로 교체합니다.

concat(
  'Title eq ''',
  replace(
    item()?['업체명'],
    '''',
    ''''''
  ),
  ''''
)

items('업체마스터안전후보반복')은 남기지 않습니다.

3. 업체마스터생성 입력값 교체

  • 제목 → 식: item()?['업체명']
  • 기본계산서업체 Id → 식: int(item()?['계산서업체ID'])
  • 사용여부 → true

4. 안전 게이트 식 유지

조건의 전체 식은 아래와 같아야 합니다.

and(
  equals(outputs('계산서마스터분류합계검증'), true),
  equals(length(body('업체마스터사전조회')?['value']), 0),
  equals(length(variables('var계산서마스터정상후보')), 27)
)

5. 저장만 확인

  1. Flow를 저장합니다.
  2. InvalidTemplate 또는 다른 저장 오류가 없는지 확인합니다.
  3. 테스트·실행 버튼은 누르지 않습니다.
  4. SharePoint 업체마스터가 계속 0건인지 확인합니다.

회신할 내용: 저장 성공 여부, 두 작업이 반복 안쪽에 있는지, 저장 오류가 없는지, 업체마스터가 계속 0건인지 알려주세요. 실제 업체명·계산서 업체명·ID는 전달하지 않습니다.
