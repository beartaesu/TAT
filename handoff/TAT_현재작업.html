TAT 현재작업 — 신규 접수 1건 실제 검증

수식은 다시 교체하거나 불러오지 않습니다.
실제로 저장해도 되는 신규 접수 1건을 사용하고, 가능하면 이번에 추가한 사용자 현장을 선택합니다.

1. Power Apps에서 저장

  1. 신규 접수 기본정보에서 업체를 선택합니다.
  2. 이번에 추가한 현장을 선택하고 계산서 업체가 정상 표시되는지 확인합니다.
  3. 실제 시료명·시료수·분석항목·수량·단가를 정상 입력합니다.
  4. 검토 화면에서 현장명이 새 현장명으로 표시되는지 확인합니다.
  5. btn최종저장을 한 번만 누릅니다.
  6. 처리 중에는 버튼을 다시 누르지 않습니다.

2. 저장 직후 확인

  1. Power Apps에 성공 알림이 표시되고 완료 화면으로 이동합니다.
  2. 새 접수번호가 정상 발급됩니다.
  3. 접수헤더가 정확히 1건 생성됩니다.
  4. 접수헤더의 업체/현장 Lookup이 선택한 새 현장을 가리킵니다.
  5. 접수헤더의 계산서 업체 Lookup이 화면 표시값과 일치합니다.
  6. 접수항목상세 건수와 입력 분석항목이 일치하고 접수헤더 Lookup이 정상입니다.
  7. 9월 접수이므로 접수시료항목매핑이 시료별 선택 내용과 일치합니다.

3. Flow와 결과 파일 확인

  1. TAT_결과파일생성_App 실행이 성공합니다.
  2. 결과 폴더와 Excel 파일이 한 번씩만 생성됩니다.
  3. 접수헤더의 결과 폴더·Excel 이름과 경로가 채워집니다.
  4. Excel의 업체/현장명과 접수번호가 실제 입력값과 일치합니다.
  5. 중복 헤더·상세·매핑·폴더·Excel이 없습니다.

4. 알려줄 결과

  • 발급된 접수번호와 접수헤더 ID
  • 접수항목상세 건수
  • 접수시료항목매핑 건수
  • Flow 성공/실패
  • 결과 폴더·Excel 생성 여부
  • 업체/현장 Lookup과 계산서 업체 Lookup 정상 여부
