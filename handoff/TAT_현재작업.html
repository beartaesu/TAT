갱신일: 2026-09-02

현재 작업: 표시순서가 들어간 표준소요일수 매핑 및 시험 데이터 교정
중요: Flow 재실행 없음, 헤더·상세 행 삭제 없음

확정된 문제

상세반복_접수항목상세생성의 표준소요일수에 사용한 OData__xd45c__xc2dc__xc21c__xc11c_ 값은 실제로 분석항목마스터의 표시순서였습니다. 기본소요일수는 현재 공란이므로 이관 상세의 표준소요일수도 공란이어야 합니다.

1. Power Automate 매핑 교정

  1. Power Automate → TAT_이관_시험조회 → 편집으로 들어갑니다.
  2. 정확한 위치: 시험이관가능조건 → True → 시험상세행반복 → 상세반복_접수항목상세생성
  3. 고급 매개 변수의 표준소요일수를 찾습니다.
  4. 기존 아래 식을 전부 삭제합니다.
int(first(body('상세반복_분석항목조회')?['value'])?['OData__xd45c__xc2dc__xc21c__xc11c_'])
  1. 표준소요일수 입력칸을 완전히 비워 둡니다.
  2. Flow를 저장합니다.
  3. Flow를 테스트하거나 다시 실행하지 않습니다.

2. 이미 생성된 시험 상세 25건 교정

  1. SharePoint → 접수항목상세로 이동합니다.
  2. 이번 시험 접수헤더에 연결된 25건만 보이도록 필터링합니다.
  3. 그리드 보기에서 편집을 누릅니다.
  4. 25건의 표준소요일수 셀만 모두 공란으로 지웁니다.
  5. 그리드 편집을 종료하고 값이 저장됐는지 확인합니다.

3. 최종 확인

  • Flow의 표준소요일수 입력이 비어 있고 저장 성공
  • 시험 상세 25건의 표준소요일수가 모두 공란
  • 분석항목 Lookup·배정시료명·수량·단가·분석상태 등 다른 열은 변경되지 않음
  • 접수헤더 1건과 접수항목상세 25건은 그대로 유지
행을 삭제하지 말고 표준소요일수 값만 지우세요.
기본소요일수가 실제로 입력·운영되기 전까지 표시순서나 다른 숫자로 대신 채우지 않습니다.
