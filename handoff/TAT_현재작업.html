TAT 현재작업 — 콤보 표시 스키마 고정

Title 표시 속성을 반복 수정하지 않습니다. Items에서 표시 전용 열 DisplayName을 직접 만들고, Items와 DefaultSelectedItems가 같은 스키마를 반환하게 합니다. SharePoint 데이터는 변경하지 않습니다.

1. cmb업체.Items 전체 수식

Sort(
    AddColumns(
        Filter(
            현장마스터,
            기본현장여부 = true
        ),
        DisplayName,
        제목
    ),
    DisplayName,
    SortOrder.Ascending
)

2. cmb업체.DefaultSelectedItems 전체 수식

If(
    var완료접수수정모드 || var이어쓰기,
    With(
        {
            loc저장현장:
                LookUp(
                    현장마스터,
                    ID = var저장헤더.'업체/현장'.Id
                )
        },
        AddColumns(
            Filter(
                현장마스터,
                기본현장여부 = true &&
                업체명복사 = loc저장현장.업체명복사
            ),
            DisplayName,
            제목
        )
    ),
    Blank()
)

3. cmb업체 표시 속성

DisplayFields 전체값

["DisplayName"]

SearchFields 전체값

["DisplayName"]

OnChange 전체 수식

Reset(cmb현장)

OnSelect 전체 수식

false

4. cmb현장.Items 전체 수식

Sort(
    AddColumns(
        If(
            IsBlank(cmb업체.Selected),
            Filter(
                현장마스터,
                ID = -1
            ),
            Filter(
                현장마스터,
                업체명복사 = cmb업체.Selected.업체명복사
            )
        ),
        DisplayName,
        제목
    ),
    DisplayName,
    SortOrder.Ascending
)

5. cmb현장.DefaultSelectedItems 전체 수식

If(
    var완료접수수정모드 || var이어쓰기,
    AddColumns(
        Filter(
            현장마스터,
            ID = var저장헤더.'업체/현장'.Id
        ),
        DisplayName,
        제목
    ),
    If(
        IsBlank(cmb업체.Selected),
        Blank(),
        [cmb업체.Selected]
    )
)

6. cmb현장 표시 속성

DisplayFields 전체값

["DisplayName"]

SearchFields 전체값

["DisplayName"]

7. 검증

  1. 빨간 수식 오류가 없는지 먼저 확인합니다.
  2. 업체 콤보의 모든 행에 업체명이 보이고 각 행을 선택할 수 있습니다.
  3. 업체 선택값도 흰색 공란이 아니라 업체명으로 남습니다.
  4. 현장 콤보에 같은 업체의 현장명이 표시되고 기본 현장이 선택됩니다.
  5. 업체 변경 시 현장과 계산서 업체가 함께 변경됩니다.
  6. 수정·이어쓰기에서 업체와 저장 현장이 각각 정상 표시됩니다.
  7. DisplayFields/SearchFields를 다시 조회해도 ["DisplayName"]이 유지되고 ComplianceAssetId로 바뀌지 않습니다.
  8. 위임 경고가 있으면 정확한 컨트롤과 속성만 알려주세요. 목록은 500건 이하이므로 이번 단계에서는 데이터를 변경하지 않습니다.
  9. + 현장 추가는 팝업을 열고 팝업 저장 버튼은 계속 비활성 상태입니다.

이 표시 구조가 유지되는 것을 확인한 뒤 실제 신규 현장 저장을 연결합니다.
