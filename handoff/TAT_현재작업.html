TAT 현재작업 — 접수 업체·현장·계산서 업체 연동 검증

TAT-06 추가 현장 저장과 시험 데이터 정리가 완료됐습니다. 이번에는 기존 두 현장으로 접수 화면의 선택·표시 연동만 회귀 검증합니다.

검증 위치

scr접수기본정보 > con접수기본행2

검증 순서

  1. 신규 접수 상태에서 cmb업체의 업체 1건을 선택합니다.
  2. cmb현장에 기본 현장이 자동 선택되는지 확인합니다.
  3. txt계산서업체에 연결된 계산서 업체명이 표시되는지 확인합니다.
  4. cmb현장에서 기존 추가 현장을 선택합니다.
  5. txt계산서업체가 공란이 되지 않고 같은 계산서 업체명을 유지하는지 확인합니다.
  6. cmb현장에서 기본 현장을 다시 선택할 수 있는지 확인합니다.
  7. 전체 과정에서 빨간 수식 오류와 노란 위임 경고가 없는지 확인합니다.

  • 실제 업체명·현장명·계산서 업체명 회신

회신 형식

  • 기본 현장 자동 선택: 됨 / 안 됨
  • 기본 현장 계산서 업체 표시: 정상 / 공란·오류
  • 추가 현장 계산서 업체 표시: 정상·동일 / 공란·다름
  • 기본 현장 재선택: 가능 / 불가
  • 오류·위임 경고: 없음 / 있음
