현재 작업: 시료명 3개·상세 48행 접수의 두 번째 쓰기 시험
Flow 수정: 없음

첫 시험 이관 완료

접수헤더 1건, 접수항목상세 25건, Lookup·복사 열·시료명·금액·상태·완료일 공란, 과거 접수시료항목매핑 0건과 표준소요일수 교정까지 모두 정상입니다.

1. 사용할 두 번째 시험값

이전 읽기 전용 시험에서 확인했던 상세 48행·비공란 시료명 3개의 다른 접수번호를 사용합니다. 방금 이관한 25행 접수번호를 다시 사용하면 안 됩니다.

2. 실행 전 확인

  • SharePoint 접수헤더에 이 48행 시험 접수번호가 아직 없는지 확인
  • Flow TAT_이관_시험조회가 저장된 최신 상태인지 확인
  • 상세반복_접수항목상세생성 > 표준소요일수 입력이 비어 있는지 확인

3. 한 번만 실행

  1. Power Automate → TAT_이관_시험조회를 실행합니다.
  2. 수동 입력에 이전 48행 시험 접수번호를 넣습니다.
  3. 정확히 한 번만 실행하고 완료될 때까지 기다립니다.

4. 실행 기록 기대값

  • 시험접수행수 = 48
  • 기존접수건수 = 0
  • 시험시료명개수확인 = 3
  • 시험시료수확인 = 2
  • 시험분석항목불일치건수 = 0
  • 시험금액일치확인 = true
  • 시험이관가능확인 = true, True 분기 진입
  • 접수헤더 생성 성공 및 ID 존재
  • 상세 반복 48회 모두 성공
  • 시험생성상세건수 = 48
  • 생성 건수 검증 조건 True, Flow 전체 성공

5. SharePoint 직접 확인

  • 접수헤더: 해당 번호 1건, 시료수 2, 시료명 요약에 세 시료명이 순서대로 표시
  • 접수항목상세: 해당 헤더 연결 행 48건
  • 시료명 공란 원천 행은 직전 비공란 시료명이 배정시료명에 이어서 저장됨
  • 시료명이 바뀌는 경계에서 이후 행의 배정시료명도 새 시료명으로 변경됨
  • 같은 분석항목명이 여러 시료 묶음에 있더라도 행이 합쳐지거나 삭제되지 않음
  • 표준소요일수와 현재 과거 자료의 분석완료일은 모두 공란
  • 접수시료항목매핑: 신규 행 0건

알려줄 결과

  • Flow 성공/실패
  • 행 수·시료명 개수·시료수·상세 생성 건수

  • 반복 분석항목 행 보존 여부
