TAT 현재 작업

갱신일: 2026-09-03
현재 작업: 업체 선택 → 기본/사용자 현장 자동 생성 구조의 SharePoint 기반 준비
이번 단계: 목록·열만 생성, 기존 데이터 보정과 앱·Flow 수정은 아직 하지 않음
사용자가 모든 현장을 미리 만들지 않습니다. 업체를 선택하면 업체명이 기본 현장명이 되고, 사용자가 다른 현장명을 입력하면 최초 저장 때 생성됩니다. 다음부터 같은 업체의 현장 드롭다운에 표시됩니다.

1. 새 SharePoint 목록 만들기

  1. TAT SharePoint 사이트 → 사이트 콘텐츠 → 새로 만들기 → 목록 → 빈 목록을 선택합니다.
  2. 목록 이름을 정확히 업체마스터로 입력해 만듭니다.
  3. 기본 제목 열의 표시 이름을 업체명으로 바꿉니다. 열 종류는 한 줄 텍스트를 유지합니다.
  4. 업체명은 필수 예, 고유 값 적용 예로 설정합니다.

2. 업체마스터 열 추가

열 이름형식설정
기본계산서업체연결 조회(Lookup) 원본 목록 계산서업체마스터, 원본 열 제목, 여러 값 허용 아니요, 필수 아니요
사용여부 예/아니요 기본값 예

3. 기존 현장마스터 열 추가

기존 제목과 계산서 업체 연결 열은 삭제하거나 이름을 바꾸지 않습니다.

열 이름형식설정
업체연결 조회(Lookup) 원본 목록 업체마스터, 원본 열 업체명(제목), 여러 값 허용 아니요, 현재는 필수 아니요
업체ID복사 숫자 소수 자릿수 0, 필수 아니요, 기본값 없음. 생성 후 이 열에 인덱스를 만듭니다.
기본현장여부 예/아니요 기본값 아니요

4. 인덱스 만들기

  1. 현장마스터 → 설정 → 목록 설정 → 인덱싱된 열로 이동합니다.
  2. 새 인덱스에서 기본 열로 업체ID복사를 선택해 저장합니다.

완료 후 알려줄 내용

  • 업체마스터 목록 생성 완료 여부
  • 업체명 고유 값 적용 완료 여부
  • 기본계산서업체연결, 사용여부 생성 완료 여부
  • 현장마스터의 업체연결, 업체ID복사, 기본현장여부 생성 완료 여부
  • 업체ID복사 인덱스 생성 완료 여부
  • 동일한 이름의 기존 열이 발견되거나 설정이 다른 경우 그 열 이름과 현재 형식
업체마스터 데이터 행은 아직 일일이 입력하지 마세요.
기존 현장마스터 행도 아직 수정하지 마세요.
Power Apps와 Power Automate도 아직 수정·실행하지 마세요.
