현재 작업: 두 번째 시험 이관이 차단된 정확한 조건 확인

현재 판정

시험이관가능조건 = false이므로 시험접수헤더생성 이후가 건너뛴 것은 정상입니다. 접수헤더와 접수항목상세가 모두 생성되지 않았으므로 정리할 데이터도 없습니다.

확인 1 — 시험이관가능확인

  1. Power Automate → TAT_이관_시험조회 → 방금 실행한 두 번째 시험의 실행 기록을 엽니다.
  2. 시험이관가능확인을 펼칩니다.
  3. 입력과 출력이 각각 true인지 false인지 확인합니다.

확인 2 — 필터 결과의 첫 행 시료명

  1. 같은 실행 기록에서 시험접수행필터를 펼칩니다.
  2. 원시 출력 표시를 누릅니다.
  3. 출력 배열의 첫 번째 객체 한 개만 확인합니다.
  4. 그 객체의 시료명 값이 공란인지 / 공란이 아닌지만 확인합니다.

대화로 알려줄 값

  • 시험이관가능확인 입력: true / false
  • 시험이관가능확인 출력: true / false
  • 시험접수행필터 첫 배열 항목의 시료명: 공란 / 공란 아님
원시 출력 파일이나 실제 시료명은 MYBOX에 올리지 마세요. 공란 여부만 알려주세요.
지금은 Flow를 수정하거나 두 번째 접수를 다시 실행하지 마세요.
