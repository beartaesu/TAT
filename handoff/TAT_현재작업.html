TAT 현재작업 — TAT-02 Power Apps 업체마스터 연결

이번 작업은 데이터 원본 추가와 cmb업체 네 속성만 변경합니다.
cmb현장, btn현장추가저장, btn최종저장은 변경하거나 실행하지 않습니다. 업체 데이터를 수작업으로 대량 입력하지 않습니다.

1. 데이터 원본 추가

  1. Power Apps Studio에서 현재 TAT 앱을 엽니다.
  2. 왼쪽 데이터에서 데이터 추가를 선택합니다.
  3. 현재 TAT SharePoint 연결에서 업체마스터를 찾아 추가합니다.
  4. 데이터 목록에 업체마스터가 표시되는지 확인합니다.

2. 정확한 위치

scr접수기본정보 > con접수기본전체 > con접수기본본문 > con접수기본카드 > con접수기본행2 > con업체영역 > cmb업체

3. cmb업체 전체 속성 교체

Items — 기존 수식 전체 삭제 후 교체

SortByColumns(
    AddColumns(
        Filter(
            업체마스터,
            사용여부 = true
        ),
        DisplayName,
        제목
    ),
    "Title",
    SortOrder.Ascending
)

DisplayFields — 기존 값 전체 교체

["DisplayName"]

SearchFields — 기존 값 전체 교체

["DisplayName"]

DefaultSelectedItems — 기존 수식 전체 삭제 후 교체

With(
    {
        loc업체목록:
            AddColumns(
                Filter(
                    업체마스터,
                    사용여부 = true
                ),
                DisplayName,
                제목
            )
    },
    If(
        var완료접수수정모드 || var이어쓰기,
        With(
            {
                loc기존현장:
                    LookUp(
                        현장마스터,
                        ID = var저장헤더.'업체/현장'.Id
                    )
            },
            Filter(
                loc업체목록,
                제목 = Coalesce(
                    loc기존현장.업체명복사,
                    loc기존현장.제목
                )
            )
        ),
        Filter(
            loc업체목록,
            ID = -1
        )
    )
)

4. 이번 단계 검증

  1. 업체마스터 데이터 원본이 정상 추가됐습니다.
  2. 위 네 속성에 빨간 수식 오류가 없습니다.
  3. 새 대규모 데이터 위임 경고가 없습니다.
  4. 현재 업체마스터가 비어 있으므로 cmb업체가 빈 목록인 것은 정상입니다.
  5. 다른 컨트롤과 btn최종저장은 변경하거나 실행하지 않았습니다.
