현재 확인된 상태

시험이관가능조건은 True였지만 시험접수헤더생성부터 후속 작업이 모두 건너뜀 처리됐습니다. 따라서 두 번째 접수의 헤더·상세는 생성되지 않은 상태로 판단합니다.

1. 실행 기록에서 조건 분기 확인

  1. Power Automate → TAT_이관_시험조회 → 해당 두 번째 실행 기록을 엽니다.
  2. 시험이관가능조건을 펼칩니다.
  3. 조건 출력의 결과가 실제 불리언 true인지 확인합니다.
  4. 실행 기록 화면에서 True 쪽 분기와 False 쪽 분기 중 어느 쪽이 실행 표시이고 어느 쪽이 회색 건너뜀인지 적어 둡니다.

2. 시험접수헤더생성 건너뜀 사유 확인

  1. 회색으로 표시된 시험접수헤더생성을 누릅니다.
  2. 표시되는 상태 코드 또는 건너뜀 코드와 메시지만 적어 둡니다.
  3. 입력·출력의 업체명, 시료명, 접수번호 등 회사 데이터는 복사하지 않습니다.

3. 현재 저장 트리 위치 확인

  1. 실행 기록을 닫고 Flow 편집 화면을 엽니다. 아직 아무것도 수정하지 않습니다.
  2. 시험이관가능조건을 펼칩니다.
  3. 시험접수헤더생성이 화면상 True 영역 안에 있는지, False 영역 안에 있는지 확인합니다.
  4. 헤더 생성 아래에 시험상세행반복이 같은 분기 안에 있는지도 확인합니다.

4. 실행 후 구성 확인

  1. 시험접수헤더생성의 점 3개 메뉴를 엽니다.
  2. 실행 후 구성(Configure run after)이 보이면 선택된 상태를 확인합니다.
  3. 성공 / 실패 / 건너뜀 / 시간 초과 중 무엇이 선택되어 있는지만 적어 둡니다.
  4. 해당 메뉴가 없으면 메뉴 없음이라고 알려주세요.

알려줄 다섯 가지

  • 조건 출력: 불리언 true인지
  • 실행 표시된 분기: True / False
  • 헤더 생성의 건너뜀 코드·메시지
  • 편집 화면의 헤더 생성 위치: True / False
  • 헤더 생성 Run after 선택 상태 또는 메뉴 없음
