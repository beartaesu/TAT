TAT 현재작업 — TAT-03B 업체별 1:1·1:N·공란 분리

검증된 Flow TAT_업체기본청구처_사전검사에 읽기 전용 분류 작업만 추가합니다.
SharePoint 항목 만들기·업데이트는 추가하지 않습니다. 실제 업체명과 계산서 업체명은 출력에서 열어볼 필요가 없으며 대화나 MYBOX 파일로 전달하지 않습니다.

기준 상태

  • 원천 행 수: 7,032
  • 업체·계산서 업체 고유 조합 수: 166
  • 업체계산서고유조합건수 아래에 다음 작업을 순서대로 추가합니다.

1. 공란 조합과 유효 조합 분리

데이터 작업의 배열 필터(Filter array)를 추가하고 이름을 업체계산서공란조합으로 바꿉니다.

보낸 사람(From)

outputs('업체계산서고유조합')

고급 모드 식

or(
  equals(trim(string(coalesce(item()?['업체명'], ''))), ''),
  equals(trim(string(coalesce(item()?['계산서업체명'], ''))), '')
)

배열 필터를 하나 더 추가하고 이름을 업체계산서유효조합으로 바꿉니다.

보낸 사람(From)

outputs('업체계산서고유조합')

고급 모드 식

and(
  not(equals(trim(string(coalesce(item()?['업체명'], ''))), '')),
  not(equals(trim(string(coalesce(item()?['계산서업체명'], ''))), ''))
)

작성(Compose) 두 개를 추가합니다.

작업 이름입력 식
업체계산서공란조합건수length(body('업체계산서공란조합'))
업체계산서유효조합건수length(body('업체계산서유효조합'))

2. 유효 업체 고유 목록 만들기

데이터 작업의 선택(Select)을 추가하고 이름을 업체목록선택으로 바꿉니다.

보낸 사람(From)

body('업체계산서유효조합')

매핑은 한 행만 만들고, 왼쪽 키는 식이 아닌 일반 글자로 직접 입력합니다.

왼쪽 키 — 일반 글자오른쪽 값 — fx 식
업체명item()?['업체명']

작성(Compose)을 추가하고 이름을 업체고유목록으로 바꿉니다.

union(
  body('업체목록선택'),
  body('업체목록선택')
)

작성(Compose)을 하나 더 추가하고 이름을 업체고유건수로 바꿉니다.

length(outputs('업체고유목록'))

3. 결과 배열 변수 두 개 준비

변수 초기화를 두 개 추가합니다. 두 변수 모두 형식은 배열이며, 초기값은 오른쪽 값의 fx 식에 json('[]')을 넣습니다.

변수 이름형식초기값
var업체일대일후보배열fx json('[]')
var업체일대다예외배열fx json('[]')

4. 업체별 조합 수로 1:1·1:N 분류

  1. 각각에 적용(Apply to each)을 추가하고 이름을 업체반복으로 바꿉니다.
  2. 반복 입력의 식은 아래와 같습니다.
outputs('업체고유목록')

업체반복의 동시성 제어는 켜지 말고 기본 순차 실행 상태로 둡니다.

업체반복 안에 배열 필터를 추가하고 이름을 현재업체조합으로 바꿉니다.

보낸 사람(From)

body('업체계산서유효조합')

고급 모드 식

equals(
  item()?['업체명'],
  items('업체반복')?['업체명']
)

현재업체조합 아래에 조건을 추가합니다. 조건의 왼쪽 식은 다음과 같고, 비교는 다음과 같음, 오른쪽은 숫자 1입니다.

length(body('현재업체조합'))

예(Yes) 분기: 배열 변수에 추가 작업을 넣습니다.

  • 변수: var업체일대일후보
  • 값의 식: first(body('현재업체조합'))

아니요(No) 분기: 배열 변수에 추가 작업을 넣습니다.

  • 변수: var업체일대다예외
  • 값의 식: items('업체반복')

5. 반복 아래에서 집계 숫자와 검산값 만들기

업체반복 컨테이너가 끝난 아래쪽에 작성(Compose) 네 개를 추가합니다.

작업 이름입력 식
업체일대일후보건수length(variables('var업체일대일후보'))
업체일대다예외건수length(variables('var업체일대다예외'))
조합분류합계검증equals(add(outputs('업체계산서공란조합건수'), outputs('업체계산서유효조합건수')), outputs('업체계산서고유조합건수'))
업체분류합계검증equals(add(outputs('업체일대일후보건수'), outputs('업체일대다예외건수')), outputs('업체고유건수'))

6. 저장·실행 및 검증

  1. Flow를 저장하고 수동으로 한 번 실행합니다.
  2. 전체 Flow와 업체반복이 성공인지 확인합니다.
  3. 조합분류합계검증과 업체분류합계검증이 모두 true인지 확인합니다.
  4. SharePoint 항목 만들기·업데이트 작업이 없는지 확인합니다.
  5. 배열의 실제 업체명은 열어보거나 전달하지 않습니다.

회신할 내용: 공란 조합 수, 유효 조합 수, 업체 고유 건수, 1:1 후보 업체 수, 1:N 예외 업체 수, 두 합계 검증값, Flow 성공 여부, SharePoint 쓰기 없음 여부만 알려주세요.
