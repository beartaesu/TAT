확정된 이관 규칙

원천 구분은 분석항목 분류 일반 / 특정 / 과불이며 의뢰구분이 아닙니다.
ES-DR- 시작 → 미접수
ENE- 시작 → 측정인
그 외 → 이관제외. 과제 접수는 현재 보류합니다.

회사 PC에서 할 작업

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집
추가 위치: 최상위의 시험분석항목불일치건수 바로 아래

완성할 트리 하단

…
├─ 시험분석항목반복
├─ 시험분석항목불일치건수   [데이터 작업 - 작성]
├─ 시험의뢰구분판정             [데이터 작업 - 작성] ← 1
└─ 시험의뢰구분유효확인         [데이터 작업 - 작성] ← 2

1. 시험의뢰구분판정

  1. 시험분석항목불일치건수 바로 아래에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험의뢰구분판정
  3. 입력의 식:
    if(startsWith(outputs('시험접수번호확인'), 'ES-DR-'), '미접수', if(startsWith(outputs('시험접수번호확인'), 'ENE-'), '측정인', '이관제외'))

2. 시험의뢰구분유효확인

  1. 시험의뢰구분판정 바로 아래에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험의뢰구분유효확인
  3. 입력의 식:
    or(equals(outputs('시험의뢰구분판정'), '미접수'), equals(outputs('시험의뢰구분판정'), '측정인'))
  4. Flow를 저장하고 같은 시험값으로 한 번 실행합니다.

알려줄 결과

  • 시험의뢰구분판정 출력이 접수번호에 맞는 미접수 또는 측정인인지
  • 시험의뢰구분유효확인 입력·출력이 true인지
  • Flow 전체 성공 여부
