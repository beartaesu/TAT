TAT-10 이관 Flow 마스터 조회 구조 확인

P0 업체·현장 구조 복구는 16/16 완료됐다. 다음은 기존 9월 이관 Flow를 현재 계산서업체마스터 + 현장마스터 구조에 맞추기 위한 읽기 전용 확인이다.

이번 단계에서는 Flow를 수정·저장·실행하지 않는다. 현재 정의만 확인한다.

확인할 위치

기존 9월 이관에 사용 중인 시험 Flow에서 아래 작업을 연다.

  • 시험현장조회
  • 시험계산서업체조회
  • 시험이관가능확인
  • 시험현장건수, 시험현장ID확인
  • 시험계산서업체건수, 시험계산서업체ID확인

전달 방법

  1. 각 작업의 메뉴에서 코드 보기를 연다.
  2. 위 작업들의 정의를 한 파일 TAT10_조회구조.txt에 복사한다.
  3. 복사가 어려우면 작업 카드의 입력값이 모두 보이도록 화면 캡처를 올린다.

회사 데이터 값이나 실행 원시 출력은 넣지 않아도 된다. 목록, 필터 쿼리, 최대 항목 수, Compose 식 등 설정만 있으면 된다.

완료 기준

  • TAT10_조회구조.txt 또는 해당 화면 캡처가 MYBOX에 있음
  • Flow 변경·저장 없음
  • Flow 실행 없음

회신

  • 조회 구조 파일 업로드: 완료 / 미완료
  • Flow 변경·실행: 없음 / 있음
