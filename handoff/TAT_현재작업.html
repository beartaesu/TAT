현재 작업: True 분기에 접수헤더 생성 작업과 전체 매핑 구성
이번 단계: 구성·저장만 하고 Flow 실행 금지

직전 작업 완료

시험이관가능확인 입력·출력은 true입니다.
시험이관가능조건은 True 분기로 진입했고 Flow 전체가 성공했습니다.

회사 PC에서 할 작업

제품: Power Automate
Flow: TAT_이관_시험조회
정확한 위치: 시험이관가능조건 → True 분기 안
추가할 작업: SharePoint → 항목 만들기(Create item)
작업 이름: 시험접수헤더생성

완성할 Flow 트리 하단

시험이관가능조건                 [제어 - 조건]
├─ True
│  └─ 시험접수헤더생성          [SharePoint - 항목 만들기]
└─ False
   └─ 작업 없음

1. 작업 추가와 대상 목록

  1. 시험이관가능조건의 True 영역에서 작업 추가를 누릅니다.
  2. SharePoint의 항목 만들기를 선택합니다. 1개 항목 가져오기나 2개 이상의 항목 가져오기가 아닙니다.
  3. 작업 이름을 시험접수헤더생성으로 바꿉니다.
  4. 사이트 주소: 기존 시험 조회 작업들과 같은 TAT SharePoint 사이트
  5. 목록 이름: 접수헤더
  6. 고급 매개 변수에서 아래 표의 열을 모두 표시합니다.

2. 접수헤더 전체 매핑

3. 이번 단계의 확인

  1. 위 필드를 모두 입력한 뒤 Flow를 저장합니다.
  2. 저장 오류가 있으면 오류가 가리키는 열 이름과 메시지만 알려주세요.
  3. 표에 없는 필드가 빨간 별표로 필수 표시되면 그 필드 이름도 알려주세요.

알려줄 결과

  • 시험접수헤더생성이 True 분기 안에 있는지
  • 표의 전체 필드가 입력됐는지
  • Flow 저장 성공 여부
  • 추가로 표시된 필수 필드가 있는지
