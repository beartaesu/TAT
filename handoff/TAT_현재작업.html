회사 PC에서 할 작업

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집
추가 위치: 최상위의 기존 시험금액일치확인 바로 아래

└─ 시험결과발송여부확인       [데이터 작업 - 작성]

1. 의뢰일자 변환

  1. 시험금액일치확인 바로 아래에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험의뢰일자확인
  3. 입력의 식:
    formatDateTime(addDays('1899-12-30', int(first(body('시험접수행필터'))?['의뢰일자'])), 'yyyy-MM-dd')

2. 비공란 시료명 필터와 개수

  1. 시험의뢰일자확인 바로 아래에 데이터 작업 → 배열 필터링을 추가합니다.
  2. 작업 이름: 시험시료명행필터, 시작 값의 식: body('시험접수행필터')
  3. 왼쪽 식: empty(trim(string(item()?['시료명']))), 연산자: 같음, 오른쪽 값: false
  4. 그 바로 아래에 데이터 작업 → 작성을 추가합니다.
  5. 작업 이름: 시험시료명개수확인, 입력의 식: length(body('시험시료명행필터'))

3. 시료명 텍스트 선택·고유화·요약

  1. 시험시료명개수확인 바로 아래에 데이터 작업 → 선택을 추가합니다.
  2. 작업 이름: 시험시료명선택, 시작 값의 식: body('시험시료명행필터')
  3. 맵 영역을 텍스트 모드로 전환하고 식 trim(string(item()?['시료명']))만 입력합니다.
  4. 그 바로 아래에 데이터 작업 → 작성을 추가하고 이름을 시험시료명고유목록으로 바꿉니다.
  5. 입력의 식: union(body('시험시료명선택'), body('시험시료명선택'))
  6. 그 바로 아래에 데이터 작업 → 작성을 추가하고 이름을 시험시료명요약확인으로 바꿉니다.
  7. 입력의 식: join(outputs('시험시료명고유목록'), ', ')

4. 결과발송여부 불리언 확인

  1. 시험시료명요약확인 바로 아래에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험결과발송여부확인
  3. 입력의 식: equals(first(body('시험접수행필터'))?['결과발송여부이관'], '예')
  4. Flow를 저장하고 같은 시험값으로 한 번 실행합니다.

알려줄 결과

  • 시험의뢰일자확인이 Excel 의뢰일자와 같은 날짜인지
  • 시험시료명개수확인 입력·출력이 1인지
  • 시험시료명요약확인이 비공란이고 Excel의 시료명과 같은지
  • 시험결과발송여부확인이 Excel의 예·아니요와 일치하는 true·false
  • Flow 전체 성공 여부
