9월 9일자 접수번호 1건으로 이관 개발 재개

업체등록 기능 검증은 완료됐다. 이제 중단했던 이관 Flow 개발로 돌아간다.

Excel 파일을 새로 만들거나 분리하지 않는다. 현재 사용 중인 원천 Excel을 그대로 사용하며, 9월 9일 이전 자료와의 중복·번호 경계 검사를 별도 작업으로 수행하지 않는다.

이번 단일 작업

  1. 현재 원천 Excel에서 9월 9일자 실제 이관 대상 접수번호 1건을 선택한다.
  2. 기존 시험 이관 Flow의 수동 입력 시험접수번호에 그 번호를 넣는다.
  3. 우선 기존 읽기·분류·마스터 조회 단계가 어디까지 정상인지 실행 결과를 확인한다.
  4. 이번 결과를 확인하기 전에는 일괄 이관으로 넘어가지 않는다.

확인할 출력

  • 시험접수번호확인: 입력한 번호와 동일
  • 시험접수행수: 0보다 큼
  • 기존접수건수: 실행 결과값
  • 시험의뢰구분: 판정 결과
  • 시험현장건수, 시험계산서업체건수: 실행 결과값
  • 시험분석항목불일치건수: 실행 결과값
  • 시험이관가능확인: true / false

결과 회신

위 출력 이름별 값과 Flow 성공·실패 여부만 회신한다. 업체명·시료명·담당자 등 회사 데이터는 전달 파일에 적지 않는다.
