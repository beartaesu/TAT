TAT 현재 작업

갱신일: 2026-09-03
현재 작업: 기존 cmb현장 트리와 속성 확인
이번 단계: 데이터 원본 새로고침과 확인만 수행
현장마스터.업체명복사와 기본현장여부 생성은 완료됐습니다. 기존 저장 기능을 깨뜨리지 않도록 현재 cmb현장 구조를 확인한 뒤 업체·현장 UI 전체 수식을 작성합니다.

1. 현장마스터 데이터 원본 새로고침

  1. Power Apps Studio에서 TAT 앱을 엽니다.
  2. 왼쪽 데이터 패널을 엽니다.
  3. 현장마스터 오른쪽의 더보기 메뉴 → 새로 고침을 누릅니다.
  4. 오류가 표시되면 이후 확인을 중단하고 오류 문구만 알려주세요.

2. 정확한 트리 위치 확인

  1. 트리 보기에서 scr접수기본정보를 펼칩니다.
  2. cmb현장을 찾습니다.
  3. 화면부터 cmb현장까지의 부모 이름을 순서대로 적습니다.
  4. cmb현장과 같은 부모 바로 아래에 있는 컨트롤 이름을 위에서 아래 순서대로 적습니다.

3. cmb현장 현재 속성 확인

속성 선택 드롭다운에서 아래 항목을 각각 선택하고, 수식 입력창에 보이는 값을 그대로 복사합니다. 속성이 보이지 않으면 없음이라고 적습니다.
  • Items
  • DefaultSelectedItems
  • OnChange
  • DisplayFields
  • SearchFields
  • SelectMultiple
  • IsSearchable

MYBOX TXT 작성 형식

트리 위치:
scr접수기본정보 > ... > cmb현장

같은 부모의 자식 순서:
1. ...
2. cmb현장
3. ...

Items:
전체 수식

DefaultSelectedItems:
전체 수식

OnChange:
전체 수식

DisplayFields:
전체 값

SearchFields:
전체 값

SelectMultiple:
값 또는 없음

IsSearchable:
값 또는 없음
