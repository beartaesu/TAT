TAT-10 누락 기본 현장 1건 생성 검증

접수번호 접두어 교정은 저장 완료됐고 수동 번호발급은 하지 않았다. 이제 중단했던 이관 시험 Flow 검증으로 복귀한다.

방금까지 사용한 동일 시험번호로 TAT_이관_시험조회를 정확히 한 번만 실행한다. 결과 확인 전 두 번째 실행은 금지한다.

실행

  1. 접수번호발급_App이 아니라 TAT_이관_시험조회를 연다.
  2. 앞선 실행에서 시험현장건수 = 0, 시험계산서업체건수 = 1이었던 동일 시험번호를 입력한다.
  3. 한 번만 실행하고 완료될 때까지 재클릭하지 않는다.

Flow 검증

  • Flow 전체: 성공
  • 시험기본현장생성조건: 예 분기
  • 시험기본현장생성: 성공
  • 시험현장계산서업체일치확인: false — 생성 전 조회값이므로 정상
  • 시험이관가능확인: false
  • 시험접수헤더생성 이하: 건너뜀

SharePoint 검증

  • 현장마스터 신규 행: 정확히 1건
  • 제목 = 업체명복사
  • 업체명키: 공란 아님
  • 기본현장여부 = 예
  • 계산서 업체 연결: 이번에 유일 조회된 계산서 업체와 연결
  • 접수헤더·접수항목상세·접수시료항목매핑 신규 생성: 모두 없음

회신

  • Flow와 기본 현장 생성: 성공 / 실패
  • 관계 검사·전체 이관 가능: false / 다른 값
  • 헤더 이하: 건너뜀 / 실행됨
  • 기본 현장 필드·Lookup: 정상 / 이상
  • 접수 관련 신규 생성: 없음 / 있음
