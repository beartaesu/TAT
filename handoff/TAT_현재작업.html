TAT 현재작업 — TAT-04B 안전 게이트 오른쪽 Boolean 교정·저장

이번 단계에서는 Flow를 다시 실행하지 않습니다.
조건 오른쪽의 누락값만 추가하고 저장합니다. 직전 실행은 False 분기의 종료로 차단됐으므로 업체마스터 생성 작업은 실행되지 않았습니다.

확인된 실패 원인

업체마스터안전적재조건의 왼쪽은 Boolean을 반환하는 and(...) 식이고 연산자는 다음과 같음인데, 오른쪽 비교값이 비어 있었습니다.

오른쪽에는 문자열 "true"가 아니라 fx 식 Boolean true가 필요합니다.

1. 조건 카드 교정

  1. TAT_업체마스터_안전적재의 업체마스터안전적재조건을 엽니다.
  2. 왼쪽의 기존 전체 fx 식은 아래와 같은지 확인하고 그대로 유지합니다.
and(
  equals(outputs('계산서마스터분류합계검증'), true),
  equals(length(body('업체마스터사전조회')?['value']), 0),
  equals(length(variables('var계산서마스터정상후보')), 27)
)
  1. 가운데 연산자는 다음과 같음을 유지합니다.
  2. 오른쪽 입력칸을 선택하고 fx 식 탭에서 아래 값만 입력합니다.
true

따옴표를 붙이지 않습니다. 동적 콘텐츠의 글자값이 아니라 fx 식으로 입력된 Boolean이어야 합니다.

2. 저장만 확인

  1. Flow를 저장합니다.
  2. 저장 오류가 없는지 확인합니다.
  3. 테스트·실행 버튼은 누르지 않습니다.
  4. SharePoint 업체마스터가 계속 0건인지 확인합니다.

회신할 내용: 오른쪽에 fx Boolean true 입력 여부, 저장 성공 여부, 업체마스터 0건 유지 여부만 알려주세요.
