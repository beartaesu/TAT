TAT 현재작업 — TAT-04A 안전적재 Flow 복사 및 사전검사

이번 단계는 여전히 읽기 전용입니다.
검증된 기존 Flow는 보존하고 별도 복사본을 만든 뒤 업체마스터의 현재 건수만 확인합니다. SharePoint 항목 만들기·업데이트는 아직 추가하지 않습니다.

완료된 분류 기준

  • 원천 7,032행, 고유 조합 166건
  • 공란 1건, 유효 조합 165건
  • 업체 163개: 1:1 후보 161개, 1:N 예외 2개
  • 1:1 후보의 계산서업체마스터 대조: 정상 27개, 미일치 134개, 중복 0개
  • 모든 분류 합계 검증 true

1. 검증된 Flow를 별도 복사

  1. Power Automate의 기존 TAT_업체기본청구처_사전검사 상세 화면을 엽니다.
  2. 다른 이름으로 저장(Save As)을 사용해 복사본을 만듭니다.
  3. 복사본 이름은 TAT_업체마스터_안전적재로 지정합니다.
  4. 원본 TAT_업체기본청구처_사전검사는 수정하지 않습니다.
  5. 복사본 편집 화면에서 기존 마지막 결과가 계산서마스터분류합계검증 = true가 되는 검증본과 동일한지 확인합니다.

2. 업체마스터 현재 행 조회

복사본의 마지막 계산서마스터분류합계검증 바로 아래 최상위 단계에 SharePoint 2개 이상의 항목 가져오기(Get items)를 추가하고 이름을 업체마스터사전조회로 바꿉니다.

  • 사이트 주소: 현재 TAT SharePoint 사이트
  • 목록 이름: 업체마스터
  • 위쪽 개수(Top Count): 2
  • 필터 쿼리·정렬·폴더 제한·중첩 항목 제한: 모두 비움

이 작업은 존재 여부만 확인하므로 최대 2건만 읽습니다.

3. 업체마스터 사전 건수 계산

업체마스터사전조회 바로 아래에 작성(Compose)을 추가하고 이름을 업체마스터사전건수로 바꿉니다.

입력의 fx 식에 아래 전체 표현식을 넣습니다.

length(body('업체마스터사전조회')?['value'])

4. 저장·실행 및 검증

  1. 복사본 Flow를 저장하고 수동으로 한 번 실행합니다.
  2. 전체 Flow가 성공인지 확인합니다.
  3. 계산서마스터분류합계검증이 true인지 확인합니다.
  4. 업체마스터사전건수를 확인합니다. 현재 예상값은 0입니다.
  5. 0이 아니면 아무것도 삭제하거나 수정하지 말고 건수만 보고합니다.
  6. Flow 트리에 SharePoint 항목 만들기·업데이트 작업이 없는지 확인합니다.
  7. 실제 업체명·계산서 업체명·ID·배열 내용은 전달하지 않습니다.

회신할 내용: 복사본 Flow 생성 여부, 전체 성공 여부, 계산서마스터 합계 검증값, 업체마스터 사전 건수, SharePoint 쓰기 작업 없음 여부만 알려주세요.
