직전 작업 완료

기존접수조회는 SharePoint 2개 이상의 항목 가져오기로 정확히 실행됐습니다.
응답 200, 출력 0건이므로 시험 접수는 현재 접수헤더에 없습니다.

회사 PC에서 할 작업

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집
추가 위치: 기존 기존접수조회 작업 바로 아래의 +

완성할 Flow 트리

Power Automate
└─ 내 흐름
   └─ TAT_이관_시험조회 (편집)
      ├─ 수동으로 흐름 트리거
      ├─ 시험접수번호확인          [데이터 작업 - 작성]
      ├─ 테이블에 있는 행 나열     [Excel Online (Business)]
      ├─ 시험접수행필터             [데이터 작업 - 배열 필터링]
      ├─ 시험접수행수               [데이터 작업 - 작성]
      ├─ 기존접수조회               [SharePoint - 2개 이상의 항목 가져오기]
      └─ 기존접수건수               [데이터 작업 - 작성] ← 지금 추가

정확한 추가 순서

  1. 기존접수조회 바로 아래의 +를 누르고 작업 추가를 선택합니다.
  2. 데이터 작업 → 작성을 선택합니다.
  3. 새 작성 작업의 이름을 기존접수건수로 바꿉니다.
  4. 입력에서 식을 선택해 아래 전체 식을 입력합니다.
    length(body('기존접수조회')?['value'])
  5. Flow를 저장하고 앞에서 사용한 같은 시험값으로 수동 실행합니다.

알려줄 결과

  • 기존접수건수 출력이 0인지
  • Flow 전체 성공 여부
