저장 완료된 TAT_업체마스터_안전적재를 더 수정하지 않고 한 번만 실행합니다. 실패하거나 일부만 생성되면 항목을 삭제하거나 재실행하지 않습니다.

확인 완료된 실행 전 기준

  • 9월 8일 최종 데이터 행이 tblTATMigration 내부
  • 최신 계산서마스터 정상후보 27개·분류 합계 검증 true
  • 작업명 참조 오타 교정 후 Flow 저장 오류 없음
  • SharePoint 업체마스터 현재 0건

1. 실행 직전 확인

  1. TAT_업체마스터_안전적재를 엽니다.
  2. 마지막 저장 이후 Flow 구조나 식을 추가로 변경하지 않습니다.
  3. SharePoint 업체마스터가 여전히 0건인지 확인합니다.
  4. 0건이 아니면 실행하지 말고 현재 건수만 알려주세요.

2. 수동으로 한 번만 실행

  1. Flow의 수동 실행을 시작합니다.
  2. 실행 중이거나 결과 확인 중에는 다시 실행하지 않습니다.
  3. 전체 실행이 끝난 뒤 아래 출력만 확인합니다.

3. 실행 결과 확인

  • 전체 Flow: 성공
  • 계산서마스터분류합계검증 = true
  • 업체마스터사전건수 = 0
  • 업체마스터생성건수 = 27
  • 업체마스터사후건수 = 27
  • 업체마스터생성검증 = true

4. SharePoint 표본 확인

  1. 업체마스터 목록의 전체 항목 수가 27건인지 확인합니다.
  2. 같은 업체 제목이 중복 생성되지 않았는지 확인합니다.
  3. 임의의 몇 건에서 제목이 비어 있지 않고, 기본계산서업체 Lookup이 연결됐으며, 사용여부가 예인지 확인합니다.
