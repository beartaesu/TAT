상태: 회사 PC 작업 대기

이 작업의 목적

Excel 데이터를 다른 Excel로 옮기는 작업이 아닙니다. 최종적으로 Power Automate를 사용해 아래 TAT SharePoint 목록으로 나누어 저장합니다.

  • 접수헤더: 같은 접수번호를 1건으로 묶어 접수 기본정보·업체·계산서 업체·금액·결과발송여부 저장
  • 접수항목상세: 원본의 분석항목 행별로 분석항목·수량·단가·분석상태·분석완료일 저장
  • 현장마스터 / 계산서업체마스터 / 분석항목마스터: 원본 명칭과 대조해 기존 항목의 Lookup ID 연결
  • 접수시료항목매핑: 시료와 분석항목의 실제 연결 규칙을 확인한 후 생성 여부와 방식을 확정

이번 단계에서는 아직 SharePoint로 이관하지 않습니다. 완료·진행·결과 발송 상태를 추측하지 않도록 이관용 입력값을 먼저 정리하는 단계입니다.

지금 회사 PC에서 해야 할 업무

  1. 현재 로우데이터 Excel을 복사해 이관 작업본을 만듭니다.
  2. 원본 파일은 수정하지 않습니다.
  3. 이관 작업본의 마지막 열 오른쪽에 아래 세 열을 추가합니다.
  4. 기존에 별도 Excel에 표기했던 완료·진행·결과 발송 정보를 보고 세 열을 채웁니다.
추가 열 이름허용값입력 기준
분석상태이관대기 / 분석 중 / 분석완료 / 보류분석항목 행별로 입력
분석완료일이관날짜 또는 공란분석완료 행은 확인 가능한 날짜, 나머지는 공란
결과발송여부이관예 / 아니요같은 접수번호의 모든 행에 동일한 값

반드시 지킬 규칙

  • 날짜·TAT·표준처리기한만 보고 완료 여부를 추정하지 않습니다.
  • 같은 접수번호라도 분석항목별 분석상태는 다를 수 있습니다.
  • 같은 접수번호의 결과발송여부는 모든 행에서 같아야 합니다.
  • 알 수 없는 상태는 임의 입력하지 말고 공란으로 둡니다.
  • 실제 데이터가 든 Excel 또는 CSV를 MYBOX 전달 폴더에 올리지 않습니다.

작업 완료 후 알려줄 내용

“이관 작업본 복사 및 상태 열 3개 추가 완료”

데이터 입력까지 끝났다면 “상태값 입력도 완료”라고 함께 알려주세요.
