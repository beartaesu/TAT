건너뜀 코드의 의미

ActionBranchingConditionNotSatisfied는 해당 작업이 선택되지 않은 조건 분기에 있어서 건너뛰었다는 뜻입니다. 현재 조건 결과가 True인데 헤더가 건너뛰었다면 헤더·상세 쓰기 시퀀스가 False 분기에 있을 가능성이 큽니다.

1. 현재 편집 화면의 분기 위치 확인

  1. Power Automate → TAT_이관_시험조회 → 편집으로 들어갑니다.
  2. 시험이관가능조건을 펼칩니다.
  3. 시험접수헤더생성과 시험상세행반복이 True 영역인지 False 영역인지 확인합니다.
  4. 아무 작업도 이동하거나 수정하지 않습니다.

2. 첫 25행 쓰기 실행 기록 확인

  1. Flow의 실행 기록에서 접수헤더 1건·상세 25건을 실제로 만들었던 첫 쓰기 실행을 엽니다.
  2. 시험이관가능확인의 출력이 true인지 false인지 확인합니다.
  3. 시험이관가능조건에서 실행된 분기가 True인지 False인지 확인합니다.

3. 첫 시험 상세의 선두 시료명 확인

첫 실행의 시험이관가능확인이 false였다면 SharePoint 접수항목상세에서 첫 번째 원천 시료명이 나오기 전 상세 행의 배정시료명이 공란인지 확인합니다. 출력이 true였다면 이 확인은 생략합니다.

알려줄 세 가지

  • 현재 헤더·상세 쓰기 시퀀스 위치: True / False
  • 첫 25행 쓰기의 시험이관가능확인: true / false
  • 첫 25행 실행에서 실제 실행된 분기: True / False
