목적: 접수번호 한 건의 Excel 행 수만 확인

회사 PC 작업 순서

  1. Power Automate에서 인스턴트 클라우드 흐름을 만들고, 트리거는 수동으로 흐름 트리거를 선택합니다. Flow 이름은 TAT_이관_시험조회로 합니다.
  2. 트리거에 텍스트 입력을 하나 추가하고 이름을 시험접수번호로 지정합니다.
  3. Excel Online (Business)의 테이블에 있는 행 나열을 추가합니다. 위치는 현재 TAT SharePoint 사이트, 문서 라이브러리는 문서, 파일은 선택기에서 루트의 개발용, 표는 tblTATMigration으로 선택합니다. 파일 확장자는 직접 추측해 입력하지 않습니다. Filter Query 등 고급 입력은 모두 비워 둡니다.
  4. 이 작업의 설정에서 페이지 매김을 켜고 임계값을 10000으로 지정합니다.
  5. 배열 필터링을 추가하고 이름을 시험접수행필터로 바꿉니다. 원본은 앞 작업의 value, 왼쪽 식은 item()?['접수번호'], 비교는 같음, 오른쪽은 트리거의 동적 콘텐츠 시험접수번호로 지정합니다.
  6. 작성을 추가하고 이름을 시험접수행수로 바꾼 뒤 식에 length(body('시험접수행필터'))를 입력합니다.

테스트와 확인

  • 실제로 존재하는 접수번호 한 건을 시험접수번호에 입력해 수동 실행합니다.
  • Flow 전체가 성공했는지 확인합니다.
  • 시험접수행수 출력이 0보다 큰지 확인합니다.
  • 대화에는 성공/실패와 숫자 행 수만 알려주세요.
