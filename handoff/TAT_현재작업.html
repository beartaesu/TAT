직전 작업 완료

상단 기존 조회는 반복_분석항목조회로 유지했습니다.
아래쪽 새 상세 조회는 상세반복_분석항목조회로 정정했습니다.

회사 PC에서 할 작업

제품: Power Automate
Flow: TAT_이관_시험조회
정확한 위치: 시험이관가능조건 → True → 시험상세행반복 안의 상세반복_분석항목조회 바로 아래
추가할 작업: SharePoint → 항목 만들기(Create item)
작업 이름: 상세반복_접수항목상세생성

완성할 관련 트리

시험이관가능조건
└─ True
   ├─ 시험접수헤더생성                 [SharePoint - 항목 만들기]
   └─ 시험상세행반복                   [제어 - 각각에 적용 / 동시성 1]
      ├─ 반복_시료명존재조건
      │  ├─ Yes → 반복_현재시료명설정
      │  └─ No  → 작업 없음
      ├─ 상세반복_분석항목조회         [SharePoint - 2개 이상의 항목 가져오기]
      └─ 상세반복_접수항목상세생성     [SharePoint - 항목 만들기]

1. 대상 목록 선택

  1. 상세반복_분석항목조회 바로 아래에 SharePoint → 항목 만들기를 추가합니다.
  2. 작업 이름을 상세반복_접수항목상세생성으로 바꿉니다.
  3. 사이트 주소: 기존 조회 작업과 같은 TAT SharePoint 사이트
  4. 목록 이름: 접수항목상세
  5. 고급 매개 변수에서 아래 표의 열을 모두 표시합니다.

3. 분석완료일 전체 식

현재 8월 시험 데이터는 공란이므로 SharePoint에도 공란으로 저장합니다. 값이 있는 행은 의뢰일자와 동일한 Excel 날짜 일련번호 방식으로 변환합니다.

if(
  empty(trim(string(items('시험상세행반복')?['분석완료일이관']))),
  null,
  formatDateTime(
    addDays(
      '1899-12-30',
      int(float(items('시험상세행반복')?['분석완료일이관']))
    ),
    'yyyy-MM-dd'
  )
)

4. 이번 단계의 확인

  1. 위 필드를 모두 입력한 뒤 Flow를 저장합니다.
  2. 표에 없는 필드가 빨간 별표로 필수 표시되면 해당 필드 이름을 알려주세요.
  3. 저장 오류가 있으면 상세반복_접수항목상세생성에서 오류가 표시된 열 이름과 메시지를 알려주세요.

  • 표에 없던 추가 필수 필드가 표시됐는지
