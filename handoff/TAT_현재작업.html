TAT 현재작업

이번 작업은 현장 추가 팝업의 화면·열기·닫기만 만듭니다.
실제 SharePoint 저장은 아직 연결하지 않습니다. 아래 btn현장추가저장은 반드시 비활성 상태로 두고, 이번 검증 중에는 btn최종저장을 누르지 마세요.

1. 추가할 트리

scr접수기본정보
├─ con접수기본전체
│  └─ con접수기본본문
│     └─ con접수기본카드
│        └─ con접수기본행2
│           └─ con현장영역
│              ├─ lbl현장
│              ├─ cmb현장
│              └─ btn현장추가              ← 신규 버튼
└─ con현장추가패널                          ← 화면 루트의 신규 일반 컨테이너
   └─ con현장추가카드                       ← 신규 세로 컨테이너
      ├─ lbl현장추가제목
      ├─ lbl현장추가안내
      ├─ txt현장추가명
      └─ con현장추가버튼행                  ← 신규 가로 컨테이너
         ├─ btn현장추가취소
         └─ btn현장추가저장

con현장추가패널은 con접수기본전체 안에 넣지 말고 scr접수기본정보 바로 아래에 만드세요. 만든 뒤 트리에서 맨 앞으로 이동하여 기존 화면 위에 표시되게 합니다.

2. 현장 추가 버튼

정확한 위치

scr접수기본정보 > con접수기본전체 > con접수기본본문 > con접수기본카드 > con접수기본행2 > con현장영역 > btn현장추가

Text 전체값

"+ 현장 추가"

DisplayMode 전체 수식

DisplayMode.Edit

OnSelect 전체 수식

If(
    IsBlank(cmb업체.Selected),
    Notify(
        "업체를 먼저 선택해 주세요.",
        NotificationType.Warning
    ),
    Set(var현장추가패널, true);
    Reset(txt현장추가명)
)

3. 화면 루트 팝업

con현장추가패널

  • Visible 전체 수식: var현장추가패널
  • X: 0
  • Y: 0
  • Width: Parent.Width
  • Height: Parent.Height
  • Fill: RGBA(0, 0, 0, 0.35)

패널이 기존 화면 뒤에 보이면 트리에서 맨 앞으로 이동하세요.

con현장추가카드

  • 세로 컨테이너 권장
  • Width: 520
  • Height: 280
  • X: (Parent.Width - Self.Width) / 2
  • Y: (Parent.Height - Self.Height) / 2
  • Fill: Color.White
  • 안쪽 여백은 20, 컨트롤 간 간격은 12 정도로 설정

4. 팝업 내부 컨트롤

lbl현장추가제목.Text

"현장 추가"

lbl현장추가안내.Text

"선택 업체: " & cmb업체.Selected.제목

txt현장추가명.Default

Coalesce(
    cmb업체.Selected.업체명복사,
    cmb업체.Selected.제목
)

HintText가 있는 입력 컨트롤이면 전체값을 "현장명을 입력해 주세요."로 설정하세요.

btn현장추가취소.Text

"취소"

btn현장추가취소.OnSelect 전체 수식

Set(var현장추가패널, false);
Reset(txt현장추가명)

btn현장추가저장.Text

"저장"

btn현장추가저장.DisplayMode 전체 수식

DisplayMode.Disabled

btn현장추가저장.OnSelect 전체 수식

false

5. 검증할 항목

  1. 업체를 선택하지 않고 + 현장 추가를 누르면 경고만 표시되고 팝업은 열리지 않는다.
  2. 업체를 선택한 뒤 누르면 기존 화면 위에 음영 배경과 흰색 카드가 열린다.
  3. 안내에 선택 업체명이 표시된다.
  4. 현장명 입력란의 기본값이 선택 업체명과 같다.
  5. 취소를 누르면 팝업이 닫힌다.
  6. 저장 버튼은 비활성 상태다.
  7. Power Apps 수식 오류와 위임 경고가 새로 생기지 않는다.
  8. 기존 업체 선택, 현장 선택, 계산서 업체 표시, 다음 화면 이동이 그대로 정상이다.

위 8가지만 확인한 뒤 결과를 알려주세요. 다음 작업에서 중복 방지와 SharePoint 현장 생성 수식을 붙입니다.
