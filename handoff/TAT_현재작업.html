TAT 현재작업 — 신규 현장 저장 연결

이번에는 실제 SharePoint 현장마스터 행을 생성합니다. 실제로 추가해도 되는 업체와 현장명으로 검증하세요. 기본 화면 버튼은 패널 열기만 수행하고, Patch 수식은 팝업의 btn현장추가저장에만 넣습니다. btn최종저장은 아직 누르지 않습니다.

1. cmb업체.OnChange 전체 수식

Set(var신규현장ID, 0);
Reset(cmb현장)

2. 기본 화면 btn현장추가.OnSelect 전체 수식

위치: con현장영역 > con현장입력행 > btn현장추가

If(
    IsBlank(cmb업체.Selected),
    Notify(
        "업체를 먼저 선택해 주세요.",
        NotificationType.Warning
    ),
    Set(var신규현장ID, 0);
    Set(var현장추가패널, true);
    Reset(txt현장추가명)
)

3. cmb현장.DefaultSelectedItems 전체 수식

If(
    var신규현장ID > 0,
    AddColumns(
        Filter(
            현장마스터,
            ID = var신규현장ID
        ),
        DisplayName,
        제목
    ),
    If(
        var완료접수수정모드 || var이어쓰기,
        AddColumns(
            Filter(
                현장마스터,
                ID = var저장헤더.'업체/현장'.Id
            ),
            DisplayName,
            제목
        ),
        If(
            IsBlank(cmb업체.Selected),
            Blank(),
            [cmb업체.Selected]
        )
    )
)

4. btn현장추가저장.DisplayMode 전체 수식

위치: scr접수기본정보 > con현장추가패널 > con현장추가카드 > con현장추가버튼행 > btn현장추가저장

If(
    IsBlank(cmb업체.Selected) ||
    IsBlank(Trim(txt현장추가명.Text)),
    DisplayMode.Disabled,
    DisplayMode.Edit
)

5. btn현장추가저장.OnSelect 전체 수식

With(
    {
        loc업체명:
            cmb업체.Selected.업체명복사,
        loc현장명:
            Trim(txt현장추가명.Text)
    },
    Set(var현장저장성공, false);
    Set(var신규현장ID, 0);

    ClearCollect(
        col동일업체현장,
        FirstN(
            Filter(
                현장마스터,
                업체명복사 = loc업체명 &&
                제목 = loc현장명
            ),
            2
        )
    );

    If(
        CountRows(col동일업체현장) > 1,
        Notify(
            "같은 업체에 동일한 현장명이 2건 이상 있습니다. 현장마스터를 확인해 주세요.",
            NotificationType.Error
        ),

        CountRows(col동일업체현장) = 1,
        Set(
            var신규현장ID,
            First(col동일업체현장).ID
        );
        Set(var현장저장성공, true),

        IfError(
            Set(
                var신규현장ID,
                Patch(
                    현장마스터,
                    Defaults(현장마스터),
                    {
                        제목: loc현장명,
                        업체명복사: loc업체명,
                        기본현장여부: false,
                        '계산서 업체 연결':
                            cmb업체.Selected.'계산서 업체 연결'
                    }
                ).ID
            );
            Set(var현장저장성공, true),
            Notify(
                "현장 저장 중 오류가 발생했습니다: " &
                FirstError.Message,
                NotificationType.Error
            )
        )
    );

    If(
        var현장저장성공,
        Refresh(현장마스터);
        Reset(cmb현장);
        Reset(txt현장추가명);
        Set(var현장추가패널, false);
        Notify(
            "현장이 선택되었습니다.",
            NotificationType.Success
        )
    )
)

6. 적용 직후 확인

  1. 빨간 수식 오류가 없는지 확인합니다.
  2. 위임 경고가 생겼으면 정확한 컨트롤·속성을 알려주세요.
  3. 오류나 경고가 있으면 아직 저장 버튼을 누르지 않습니다.

7. 오류·경고가 없을 때 검증

  1. 실제로 추가해도 되는 업체와 새 현장명을 사용해 한 번 저장합니다.
  2. 성공 알림 후 패널이 닫히고 새 현장이 현장 콤보에 자동 선택됩니다.
  3. 계산서 업체가 선택 업체의 연결값으로 표시됩니다.
  4. 현장마스터 새 행은 입력한 제목, 같은 업체명복사, 기본현장여부=아니요, 같은 계산서 업체 연결값을 가집니다.
  5. 같은 현장명을 다시 저장하면 중복 행 없이 기존 현장이 선택됩니다.
  6. 새 현장은 업체 콤보 후보에 나타나지 않습니다.
  7. 업체 변경 후 원래 업체로 돌아오면 기본 현장과 새 현장을 모두 선택할 수 있습니다.
  8. 업체·현장 이름과 DisplayName 표시가 계속 유지됩니다.
  9. btn접수기본다음 이동은 정상이고 btn최종저장은 실행하지 않습니다.

검증 결과를 알려주세요. 성공하면 최종저장 수식의 구형 현장 참조 8곳을 전체 교체합니다.
