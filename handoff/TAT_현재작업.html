현재 작업: 상세 25행 반복·시료명 승계·분석항목 재조회 구성
이번 단계: 구성·저장만 하고 Flow 실행 금지

직전 작업 완료

True 분기의 시험접수헤더생성 전체 필드 매핑 후 Flow 저장을 완료했습니다.
아직 Flow는 실행하지 않았으므로 SharePoint에 생성된 시험 데이터는 없습니다.

회사 PC에서 할 작업

제품: Power Automate
Flow: TAT_이관_시험조회
목적: 원천 25행을 순서대로 돌며 빈 시료명은 직전 시료명으로 승계하고, 각 행의 분석항목 Lookup을 다시 조회
주의: 이번 단계에서도 접수항목상세 항목 만들기는 아직 추가하지 않습니다.

완성할 관련 트리

…
├─ 시험결과발송여부확인          [데이터 작업 - 작성]
├─ 시험현재시료명초기화          [변수 - 변수 초기화]
├─ 시험이관가능확인              [데이터 작업 - 작성]
└─ 시험이관가능조건              [제어 - 조건]
   ├─ True
   │  ├─ 시험접수헤더생성         [SharePoint - 항목 만들기]
   │  └─ 시험상세행반복           [제어 - 각각에 적용]
   │     ├─ 반복_시료명존재조건   [제어 - 조건]
   │     │  ├─ Yes
   │     │  │  └─ 반복_현재시료명설정 [변수 - 변수 설정]
   │     │  └─ No: 작업 없음
   │     └─ 반복_분석항목조회     [SharePoint - 2개 이상의 항목 가져오기]
   └─ False: 작업 없음

1. 첫 행 시료명 안전검사 추가

  1. 기존 최상위 시험이관가능확인을 엽니다.
  2. 기존 입력 식을 전부 삭제하고 아래 전체 식으로 교체합니다.
and(
  greater(int(outputs('시험접수행수')), 0),
  equals(int(outputs('기존접수건수')), 0),
  equals(int(outputs('시험현장건수')), 1),
  equals(int(outputs('시험계산서업체건수')), 1),
  equals(int(outputs('시험분석항목불일치건수')), 0),
  equals(outputs('시험의뢰구분유효확인'), true),
  equals(outputs('시험금액일치확인'), true),
  greater(int(outputs('시험시료수확인')), 0),
  not(empty(outputs('시험의뢰일자확인'))),
  not(empty(outputs('시험시료명요약확인'))),
  not(empty(trim(string(first(body('시험접수행필터'))?['시료명']))))
)

2. 현재 시료명 변수 초기화

  1. 최상위의 시험결과발송여부확인 바로 아래, 시험이관가능확인 바로 위에 변수 → 변수 초기화를 추가합니다.
  2. 작업 이름: 시험현재시료명초기화
  3. 이름: var시험현재시료명
  4. 형식: 문자열
  5. 값: 비워 둡니다.

3. True 분기에 상세 행 반복 추가

  1. 시험이관가능조건의 True 안에서 시험접수헤더생성 바로 아래에 제어 → 각각에 적용을 추가합니다.
  2. 작업 이름: 시험상세행반복
  3. 이전 단계의 출력 선택에서 식: body('시험접수행필터')
  4. 설정 → 동시성 제어는 끄거나 병렬 처리 수준을 1로 유지합니다.

4. 반복 안에서 비공란 시료명만 변수에 저장

  1. 시험상세행반복 안에 제어 → 조건을 추가하고 이름을 반복_시료명존재조건으로 바꿉니다.
  2. 왼쪽 식: empty(trim(string(items('시험상세행반복')?['시료명'])))
  3. 연산자: 같음
  4. 오른쪽 식: false
  5. 조건의 Yes 안에 변수 → 변수 설정을 추가합니다.
  6. 작업 이름: 반복_현재시료명설정
  7. 이름: var시험현재시료명
  8. 값의 식: trim(string(items('시험상세행반복')?['시료명']))
  9. No에는 아무 작업도 추가하지 않습니다. 그러면 직전 시료명이 그대로 유지됩니다.

5. 반복 행의 분석항목 다시 조회

  1. 반복_시료명존재조건 전체 조건 상자 바로 아래이면서 여전히 시험상세행반복 안에 SharePoint → 2개 이상의 항목 가져오기(Get items)를 추가합니다.
  2. 작업 이름: 반복_분석항목조회
  3. 사이트 주소: 기존 조회 작업과 같은 TAT SharePoint 사이트
  4. 목록 이름: 분석항목마스터
  5. 필터 쿼리의 식에 아래 전체 식을 입력합니다.
concat(
  'Title eq ''',
  replace(
    trim(string(items('시험상세행반복')?['분석항목'])),
    '''',
    ''''''
  ),
  ''''
)
  1. 상위 개수: 2
  2. 정렬 기준·폴더 제한 등 나머지는 비워 둡니다.

6. 저장만 하기

  1. Flow를 저장합니다.
  2. 저장 오류가 있으면 오류가 표시된 정확한 작업 이름과 메시지를 알려주세요.

알려줄 결과

  • 시험현재시료명초기화가 최상위에 저장됐는지
  • 시험상세행반복이 True 분기에서 헤더 생성 아래에 있는지
  • 시료명 조건의 Yes에 변수 설정, No는 비어 있는지
  • 반복_분석항목조회가 조건 바깥·반복 안에 있는지
  • Flow 저장 성공 여부
중요: 아직 테스트하거나 Flow를 실행하지 마세요.
