TAT 현재작업 — TAT-01 SharePoint 업체마스터 생성

Power Apps 수식은 아직 변경하지 않습니다.
현장마스터를 업체 목록으로 겸용하던 구조는 폐기합니다. 계산서업체마스터 동일명 자동 매칭 수식도 다시 사용하지 않습니다.

1. 새 목록

현재 TAT SharePoint 사이트에서 새 빈 목록을 만듭니다.

목록 이름: 업체마스터

2. 열 구성

표시 이름형식설정
제목한 줄 텍스트기본 열 유지, 업체명 입력
기본계산서업체조회(Lookup)원본 목록: 계산서업체마스터 / 원본 열: 제목 / 단일 값
사용여부예/아니요기본값: 예

3. 이번 단계 확인

  1. 업체마스터 목록이 생성됐습니다.
  2. 위 세 열의 이름과 형식이 정확합니다.
  3. 기본계산서업체에서 계산서업체마스터의 업체를 선택할 수 있습니다.
  4. 사용여부의 새 행 기본값이 예입니다.
목록만 생성한 뒤 결과를 알려주세요. 다음 단계에서 Power Apps에 업체마스터 데이터 원본을 추가하고 cmb업체를 전환합니다. 업체 데이터를 수작업으로 대량 입력하는 작업은 아직 하지 않습니다.
