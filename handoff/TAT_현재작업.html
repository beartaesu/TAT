현장별 계산서 업체 예외 선택 — UI 단계

scr접수기본정보 > con현장추가패널 > con현장추가카드

이번 단계에서는 저장 수식을 변경하지 않고 btn현장추가저장도 누르지 않는다.

1. 레이블 추가

txt현장추가명 다음에 레이블을 추가하고 이름을 lbl현장추가계산서업체로 변경한다.

  • Text = "계산서 업체"
  • Width = Parent.Width
  • Height = 24
  • FillPortions = 0
  • LayoutMinHeight = 24

2. 콤보박스 추가

레이블 다음에 콤보박스를 추가하고 이름을 cmb현장추가계산서업체로 변경한다.

  • SelectMultiple = false
  • Width = Parent.Width
  • Height = 40
  • FillPortions = 0
  • LayoutMinHeight = 40
  • DisplayFields = ["DisplayName"]
  • SearchFields = ["DisplayName"]

Items 전체 수식

SortByColumns(
    AddColumns(
        Filter(
            계산서업체마스터,
            사용여부 = true
        ),
        DisplayName,
        제목
    ),
    "Title",
    SortOrder.Ascending
)

DefaultSelectedItems 전체 수식

With(
    {
        loc기본계산서업체ID:
            LookUp(
                현장마스터,
                ID = cmb업체.Selected.ID
            ).'계산서 업체 연결'.Id
    },
    If(
        IsBlank(loc기본계산서업체ID),
        Blank(),
        AddColumns(
            Filter(
                계산서업체마스터,
                ID = loc기본계산서업체ID &&
                사용여부 = true
            ),
            DisplayName,
            제목
        )
    )
)

3. 패널 열기 버튼 전체 수식

scr접수기본정보 > btn현장추가 > OnSelect

Set(var신규현장ID, 0);
Reset(txt현장추가명);
Reset(cmb현장추가계산서업체);
Set(var현장추가패널, true)

4. 카드 높이

새 두 컨트롤이 잘릴 때만 con현장추가카드에 아래 값을 적용한다.

  • Height = 360
  • LayoutMinHeight = 360

검증

  • 오류·위임 경고 없음
  • 현장 추가 패널을 열면 선택 업체의 기본 계산서 업체가 자동 선택됨
  • 콤보 목록에서 다른 사용 중 계산서 업체를 선택할 수 있음
  • btn현장추가저장은 누르지 않음
