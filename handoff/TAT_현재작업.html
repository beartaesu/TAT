TAT 현재작업 — TAT-04B 정상후보 27개 안전적재 1회 실행

이번 실행에서 처음으로 SharePoint 업체마스터에 항목이 생성됩니다.
저장된 TAT_업체마스터_안전적재를 한 번만 실행합니다. 실패하거나 일부만 생성되면 항목을 삭제·수정하거나 Flow를 다시 실행하지 않습니다.

1. 실행 직전 마지막 확인

  1. SharePoint 업체마스터가 0건인지 확인합니다. 0건이 아니면 실행하지 않습니다.
  2. 업체마스터안전적재조건이 아래 세 칸으로 구성됐는지 확인합니다.
    • 왼쪽: 기존 and(...) 전체 fx 식
    • 가운데: 다음과 같음
    • 오른쪽: 따옴표 없는 fx Boolean true
  3. Flow 구조와 식을 추가로 수정하지 않습니다.

2. 수동으로 한 번만 실행

  1. TAT_업체마스터_안전적재를 수동으로 한 번 실행합니다.
  2. 실행 중이거나 결과 확인 중에는 다시 실행하지 않습니다.
  3. 실행이 끝난 뒤 아래 출력값을 확인합니다.

3. 정상 완료 기준

  • 전체 Flow: 성공
  • 계산서마스터분류합계검증 = true
  • 업체마스터사전건수 = 0
  • 업체마스터생성건수 = 27
  • 업체마스터사후건수 = 27
  • 업체마스터생성검증 = true

4. SharePoint 확인

  1. 업체마스터 전체 항목이 27건인지 확인합니다.
  2. 같은 업체 제목이 중복 생성되지 않았는지 확인합니다.
  3. 임의의 몇 건에서 제목이 비어 있지 않고, 기본계산서업체 Lookup이 연결됐으며, 사용여부가 예인지 확인합니다.
  4. 실제 업체명·계산서 업체명·ID는 대화나 MYBOX에 올리지 않습니다.
실패 또는 부분 생성 시: 업체마스터 항목을 삭제·수정하지 말고 Flow도 재실행하지 않습니다. 실패한 작업 이름과 확인 가능한 생성건수·사후건수만 알려주세요.

회신할 내용: Flow 성공 여부, 분류 합계 검증값, 사전 건수, 생성 건수, 사후 건수, 생성 검증값, 목록 27건 여부, 중복 없음 여부, Lookup·사용여부 표본 정상 여부만 알려주세요.
