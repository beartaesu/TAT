TAT 현재작업 — TAT-03C 계산서업체마스터 대조

검증된 1:1 후보 161개만 계산서업체마스터와 읽기 전용으로 대조합니다.
SharePoint 2개 이상의 항목 가져오기만 사용하며 항목 만들기·업데이트는 추가하지 않습니다. 실제 업체명·계산서 업체명·ID는 열어보거나 전달하지 않습니다.

기준 상태

  • 공란 조합: 1건
  • 유효 조합: 165건
  • 업체 고유: 163개
  • 1:1 후보: 161개
  • 1:N 예외: 2개
  • 두 합계 검증값: 모두 true

1. 계산서업체마스터 대조 결과 변수 준비

기존 업체일대일후보건수·업체일대다예외건수·합계 검증 작업 아래의 최상위 단계에 변수 초기화 세 개를 추가합니다. 새 반복 작업보다 반드시 위에 둡니다.

변수 NameTypeValue의 fx 식
var계산서마스터정상후보Arrayjson('[]')
var계산서마스터미일치Arrayjson('[]')
var계산서마스터중복Arrayjson('[]')

카드 제목만 바꾸지 말고 각 변수 초기화 작업 내부의 Name에 위 이름을 직접 입력합니다. 디자이너가 새 변수를 목록에 표시하지 않으면 해당 초기화 작업만 삭제 후 동일하게 다시 만듭니다.

2. 1:1 후보 반복

  1. 각각에 적용(Apply to each)을 추가하고 이름을 업체일대일후보반복으로 바꿉니다.
  2. 반복 입력의 fx 식은 아래와 같습니다.
variables('var업체일대일후보')

동시성 제어는 켜지 말고 기본 순차 실행 상태로 둡니다.

3. 반복 안에서 계산서업체마스터 조회

업체일대일후보반복 안에 SharePoint 2개 이상의 항목 가져오기(Get items)를 추가하고 이름을 계산서업체마스터조회로 바꿉니다.

  • 사이트 주소: 현재 TAT SharePoint 사이트
  • 목록 이름: 계산서업체마스터
  • 필터 쿼리: 아래 fx 식 전체
  • 위쪽 개수(Top Count): 2
  • 정렬·폴더 제한·중첩 항목 제한: 비움
concat(
  'Title eq ''',
  replace(
    items('업체일대일후보반복')?['계산서업체명'],
    '''',
    ''''''
  ),
  ''''
)

조회 아래에 작성(Compose)을 추가하고 이름을 계산서업체마스터건수로 바꿉니다.

length(body('계산서업체마스터조회')?['value'])

4. 1건·0건·2건 이상 분류

계산서업체마스터건수 아래에 조건을 추가하고 이름을 계산서업체유일일치조건으로 바꿉니다.

  • 왼쪽 fx: outputs('계산서업체마스터건수')
  • 연산자: 다음과 같음
  • 오른쪽 숫자: 1

True — 정확히 1건: 배열 변수에 추가

  • Name: var계산서마스터정상후보
  • Value의 fx 식:
addProperty(
  items('업체일대일후보반복'),
  '계산서업체ID',
  first(body('계산서업체마스터조회')?['value'])?['ID']
)

False 안에 두 번째 조건을 추가하고 이름을 계산서업체미일치조건으로 바꿉니다.

  • 왼쪽 fx: outputs('계산서업체마스터건수')
  • 연산자: 다음과 같음
  • 오른쪽 숫자: 0

두 번째 조건 True — 0건: 배열 변수에 추가

  • Name: var계산서마스터미일치
  • Value의 fx: items('업체일대일후보반복')

두 번째 조건 False — 2건 이상: 배열 변수에 추가

  • Name: var계산서마스터중복
  • Value의 fx: items('업체일대일후보반복')

5. 반복 아래에서 집계 숫자와 검산값 만들기

업체일대일후보반복 컨테이너가 끝난 아래쪽 최상위 단계에 작성(Compose) 네 개를 추가합니다.

작업 이름입력 fx 식

계산서마스터미일치건수length(variables('var계산서마스터미일치'))

계산서마스터분류합계검증equals(add(add(outputs('계산서마스터정상후보건수'), outputs('계산서마스터미일치건수')), outputs('계산서마스터중복건수')), outputs('업체일대일후보건수'))

6. 저장·실행 및 검증

  1. Flow를 저장하고 수동으로 한 번 실행합니다.
  2. 전체 Flow와 업체일대일후보반복이 성공인지 확인합니다.
  3. 계산서마스터분류합계검증이 true인지 확인합니다.
  4. 정상·미일치·중복 건수의 합이 기존 1:1 후보 161개인지 확인합니다.
  5. SharePoint 항목 만들기·업데이트 작업이 없는지 확인합니다.
  6. 실제 명칭·ID·배열 내용은 열어보거나 전달하지 않습니다.
