TAT 현재작업 — TAT-04B 작업명 오타 교정·저장

이번 단계에서는 Flow를 실행하지 않습니다.
작업명 참조의 오타만 교정한 뒤 저장 성공만 확인합니다. 실행하면 최초로 SharePoint 업체마스터 쓰기가 발생할 수 있으므로 실행은 다음 확인 전까지 금지합니다.

확정된 안전 기준

  • 9월 8일 최종 데이터 행은 tblTATMigration 내부
  • 최신 계산서마스터 정상후보: 27개
  • SharePoint 업체마스터 사전 건수: 0개

1. 확인된 원인

정확한 작업명은 업체마스터업체중복조회인데 참조에 체마스터업체중복조회로 입력하여 맨 앞의 업이 빠졌습니다.

반복 구조 문제가 아니므로 작업 위치나 반복 항목 식을 변경하지 않습니다.

2. 오타만 교정

  1. TAT_업체마스터_안전적재를 편집합니다.
  2. 오타가 있는 참조 체마스터업체중복조회를 찾습니다.
  3. 맨 앞에 업을 추가하여 업체마스터업체중복조회와 정확히 일치시킵니다.
  4. 앞서 안내된 item() 식 교체는 적용하지 않습니다. 이미 적용했다면 저장하지 말고 기존 식으로 되돌립니다.

3. 안전 게이트 식 유지

조건의 전체 식은 아래와 같아야 합니다.

and(
  equals(outputs('계산서마스터분류합계검증'), true),
  equals(length(body('업체마스터사전조회')?['value']), 0),
  equals(length(variables('var계산서마스터정상후보')), 27)
)

4. 저장만 확인

  1. Flow를 저장합니다.
  2. InvalidTemplate 또는 다른 저장 오류가 없는지 확인합니다.
  3. 테스트·실행 버튼은 누르지 않습니다.
  4. SharePoint 업체마스터가 계속 0건인지 확인합니다.

회신할 내용: 오타 교정 후 저장 성공 여부, 저장 오류가 없는지, 업체마스터가 계속 0건인지 알려주세요. 실제 업체명·계산서 업체명·ID는 전달하지 않습니다.
