TAT 현재 작업

갱신일: 2026-09-02
Git 기준: main / 916df0a
현재 작업: 새 상세 반복의 분석항목 조회 작업 이름 정정
이번 단계: 이름 변경·저장만 하고 Flow 실행 금지

확인된 문제

상단의 기존 시험분석항목반복 안에 이미 반복_분석항목조회가 있습니다. 아래쪽 새 시험상세행반복에도 같은 이름을 사용하도록 안내한 것은 잘못입니다. 저장되더라도 Power Automate 내부 이름에 자동 접미사가 붙어 이후 식 참조가 불명확해질 수 있습니다.

회사 PC에서 할 작업

  1. Power Automate → TAT_이관_시험조회 → 편집으로 들어갑니다.
  2. 정확한 위치: 시험이관가능조건 → True → 시험상세행반복
  3. 그 안의 새 SharePoint 조회 작업 반복_분석항목조회 이름만 아래와 같이 변경합니다.
기존 이름: 반복_분석항목조회
새 이름:   상세반복_분석항목조회

변경 후 관련 트리

시험분석항목반복
└─ 반복_분석항목조회          ← 기존 상단 작업, 변경 금지

시험이관가능조건
└─ True
   ├─ 시험접수헤더생성
   └─ 시험상세행반복
      ├─ 반복_시료명존재조건
      └─ 상세반복_분석항목조회 ← 새 아래쪽 작업

확인

  • 상단 기존 이름은 반복_분석항목조회 그대로인지
  • 아래쪽 새 이름은 상세반복_분석항목조회인지
  • Flow 저장이 성공하는지
이번에도 Flow를 테스트하거나 실행하지 마세요.
