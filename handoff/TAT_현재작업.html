직전 작업 완료

상세반복_접수항목상세생성 전체 필드 매핑 후 Flow 저장을 완료했습니다.
아직 실행하지 않았으므로 SharePoint 시험 데이터는 생성되지 않았습니다.

완성할 관련 트리

…
├─ 시험현재시료명초기화            [변수 - 문자열 초기화]
├─ 시험생성상세건수초기화          [변수 - 정수 초기화]
├─ 시험이관가능확인
└─ 시험이관가능조건
   ├─ True
   │  ├─ 시험접수헤더생성
   │  ├─ 시험상세행반복
   │  │  ├─ 반복_시료명존재조건
   │  │  ├─ 상세반복_분석항목조회
   │  │  ├─ 상세반복_접수항목상세생성
   │  │  └─ 상세반복_생성건수증가
   │  ├─ 시험생성상세건수
   │  └─ 시험생성건수검증조건
   │     ├─ True → 시험이관완료요약
   │     └─ False → 시험이관실패종료
   └─ False: 작업 없음

1. 상세 생성 건수 변수 초기화

  1. 최상위의 시험현재시료명초기화 바로 아래이면서 시험이관가능확인보다 위에 변수 → 변수 초기화를 추가합니다.
  2. 작업 이름: 시험생성상세건수초기화
  3. 이름: var시험생성상세건수
  4. 형식: 정수
  5. 값: 0

2. 상세 생성 성공 직후 건수 증가

  1. 정확한 위치: 시험이관가능조건 → True → 시험상세행반복 안
  2. 상세반복_접수항목상세생성 바로 아래에 변수 → 변수 증가를 추가합니다.
  3. 작업 이름: 상세반복_생성건수증가
  4. 이름: var시험생성상세건수
  5. 값: 1

3. 반복 종료 후 생성 건수 출력

  1. 시험상세행반복 전체 상자 바로 아래이면서 True 분기 안에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험생성상세건수
  3. 입력의 식: variables('var시험생성상세건수')

4. 원천 행 수와 생성 성공 건수 비교

  1. 시험생성상세건수 바로 아래에 제어 → 조건을 추가합니다.
  2. 작업 이름: 시험생성건수검증조건
  3. 왼쪽 값: 시험생성상세건수의 출력 동적 콘텐츠
  4. 연산자: 같음
  5. 오른쪽 식: int(outputs('시험접수행수'))

5. True 분기 완료 요약

  1. 시험생성건수검증조건의 True 안에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험이관완료요약
  3. 입력에서 아래 전체 식을 사용합니다.
concat(
  '접수번호=',
  string(outputs('시험접수번호확인')),
  ' / 헤더ID=',
  string(body('시험접수헤더생성')?['ID']),
  ' / 상세생성=',
  string(outputs('시험생성상세건수')),
  '건'
)

6. False 분기 실패 종료

  1. 시험생성건수검증조건의 False 안에 제어 → 종료(Terminate)를 추가합니다.
  2. 작업 이름: 시험이관실패종료
  3. 상태: 실패(Failed)
  4. 코드: MigrationDetailCountMismatch
  5. 메시지에서 아래 전체 식을 사용합니다.
concat(
  '원천 행 수 ',
  string(outputs('시험접수행수')),
  '건과 상세 생성 성공 ',
  string(outputs('시험생성상세건수')),
  '건이 일치하지 않습니다. 헤더 ID=',
  string(body('시험접수헤더생성')?['ID'])
)

7. 저장 후 첫 쓰기 실행

  1. Flow를 저장합니다.
  2. 기존에 계속 사용한 동일 시험 접수번호로 한 번만 실행합니다.
  3. 성공하면 실행 기록에서 아래 항목을 확인합니다.
  • 시험이관가능확인 = true
  • 시험접수헤더생성 성공 및 ID 존재
  • 시험상세행반복 25회 성공
  • 시험생성상세건수 입력·출력 25
  • 시험생성건수검증조건 True 분기 진입
  • 시험이관완료요약에 접수번호·헤더 ID·상세 25건 표시
  • Flow 전체 성공

8. SharePoint 직접 확인

  • 접수헤더: 시험 접수번호 1건만 생성됐는지
  • 접수항목상세: 해당 헤더에 연결된 행이 25건인지
  • 상세의 접수헤더연결과 접수헤더ID복사가 생성된 같은 헤더를 가리키는지
  • 분석항목 Lookup·배정시료명·수량·단가·분석상태가 원천과 맞는지
  • 현재 8월 자료의 분석완료일이 공란으로 유지되는지
