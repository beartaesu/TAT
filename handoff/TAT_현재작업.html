의뢰일자·시료명 개수·시료명 요약·결과발송여부가 모두 원천과 일치합니다.
새 디자이너에 맞춰 배열 변수 반복 방식의 시료명 요약을 검증했습니다.

회사 PC에서 할 작업

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집
추가 위치: 최상위의 기존 시험결과발송여부확인 바로 아래

완성할 Flow 트리 하단

…
├─ 시험결과발송여부확인   [데이터 작업 - 작성]
├─ 시험이관가능확인           [데이터 작업 - 작성]
└─ 시험이관가능조건           [제어 - 조건]
   ├─ True: 작업 없음
   └─ False: 작업 없음

1. 시험이관가능확인

  1. 시험결과발송여부확인 바로 아래에 데이터 작업 → 작성을 추가합니다.
  2. 작업 이름: 시험이관가능확인
  3. 입력에서 식을 선택하고 아래 전체 식을 입력합니다.
and(
  greater(int(outputs('시험접수행수')), 0),
  equals(int(outputs('기존접수건수')), 0),
  equals(int(outputs('시험현장건수')), 1),
  equals(int(outputs('시험계산서업체건수')), 1),
  equals(int(outputs('시험분석항목불일치건수')), 0),
  equals(outputs('시험의뢰구분유효확인'), true),
  equals(outputs('시험금액일치확인'), true),
  greater(int(outputs('시험시료수확인')), 0),
  not(empty(outputs('시험의뢰일자확인'))),
  not(empty(outputs('시험시료명요약확인')))
)

2. 시험이관가능조건

  1. 시험이관가능확인 바로 아래에 제어 → 조건을 추가합니다.
  2. 작업 이름: 시험이관가능조건
  3. 왼쪽 값에 시험이관가능확인의 출력 동적 콘텐츠를 선택합니다.
  4. 연산자: 같음, 오른쪽 값: 식에서 true
  5. True와 False 분기는 모두 비워 둡니다.
  6. Flow를 저장하고 같은 시험값으로 한 번 실행합니다.

알려줄 결과

  • 시험이관가능확인 입력·출력이 true인지
  • 시험이관가능조건이 True 분기로 진입했는지
  • Flow 전체 성공 여부
True·False 분기 안에는 아무 작업도 추가하지 마세요.
