TAT 현재작업 — TAT-03A 업체·계산서 업체 고유 조합 읽기

이번 작업은 읽기 전용 사전검사입니다.
별도 수동 Flow를 새로 만들고 기존 Excel 표를 읽기만 합니다. SharePoint의 항목 만들기·항목 업데이트 작업은 추가하지 말고, 기존 이관 Flow도 수정하지 않습니다. 실행 결과나 MYBOX 파일에 실제 업체명·계산서 업체명을 남기지 않습니다.

1. 별도 수동 Flow 생성

  1. Power Automate에서 인스턴트 클라우드 흐름을 만듭니다.
  2. 흐름 이름은 TAT_업체기본청구처_사전검사로 입력합니다.
  3. 트리거는 수동으로 흐름 트리거를 선택합니다.

2. 기존 Excel 원천 전체 읽기

  1. Excel Online (Business)의 테이블에 있는 행 나열을 추가합니다.
  2. 작업 이름을 업체계산서원천행조회로 바꿉니다.
  3. 위치와 문서 라이브러리는 현재 TAT 파일이 있는 SharePoint 사이트와 문서를 선택합니다.
  4. 파일은 직접 입력하지 말고 선택기를 열어 루트의 개발용 파일을 선택합니다.
  5. 테이블은 tblTATMigration을 선택합니다.
  6. 필터 쿼리·정렬 기준·위쪽 개수·건너뛸 개수는 모두 비워 둡니다.
  7. 작업의 설정에서 페이지 매김을 켜고 임계값을 10000으로 지정합니다.

3. 원천 행 수 계산

데이터 작업의 작성(Compose)을 추가하고 이름을 업체계산서원천행수로 바꾼 뒤, 입력의 식에 아래 전체 표현식을 넣습니다.

length(body('업체계산서원천행조회')?['value'])

4. 업체·계산서 업체 두 열만 선택

  1. 데이터 작업의 선택(Select)을 추가하고 이름을 업체계산서조합선택으로 바꿉니다.
  2. 보낸 사람(From)의 식에 아래 표현식을 넣습니다.
body('업체계산서원천행조회')?['value']

매핑은 다음 두 행만 만듭니다.

  • 키 업체명 / 값의 식 item()?['업체']
  • 키 계산서업체명 / 값의 식 item()?['계산서 업체']

5. 고유 조합과 건수 계산

데이터 작업의 작성(Compose)을 추가하고 이름을 업체계산서고유조합으로 바꾼 뒤 아래 전체 표현식을 넣습니다.

union(
  body('업체계산서조합선택'),
  body('업체계산서조합선택')
)

작성(Compose)을 하나 더 추가하고 이름을 업체계산서고유조합건수로 바꾼 뒤 아래 전체 표현식을 넣습니다.

length(outputs('업체계산서고유조합'))

6. 저장·실행 및 이번 단계 검증

  1. 흐름을 저장하고 수동으로 한 번 실행합니다.
  2. 전체 Flow가 성공인지 확인합니다.
  3. 업체계산서원천행수 출력이 0보다 큰 숫자인지 확인합니다.
  4. 업체계산서고유조합건수 출력이 0보다 큰 숫자인지 확인합니다.
  5. Flow 트리에 SharePoint 항목 만들기·업데이트 작업이 없는지 확인합니다.
  6. 실제 업체명·계산서 업체명은 복사하거나 전달하지 않습니다.

회신할 내용: Flow 성공 여부, 원천 행 수, 고유 조합 건수, SharePoint 쓰기 작업 없음 여부만 알려주세요. 다음 TAT-03B에서 업체별 1:1·1:N·공란·계산서업체마스터 미일치를 분리합니다.
