TAT 현재작업 — TAT-03R 최신 Excel 전체 읽기 전용 재검증

업체마스터 쓰기를 중단합니다.
원천 Excel이 2026-09-08 데이터까지 갱신됐으므로 기존 7,032행·166조합·정상후보 27개는 현재 적재 기준으로 사용하지 않습니다. TAT_업체마스터_안전적재는 저장·실행하지 않습니다.

확인된 TAT-04B 오류

업체마스터업체중복조회가 템플릿에 없는 반복 이름 업체마스터안전후보반복을 참조해 InvalidTemplate 저장 오류가 발생했습니다.

Flow가 저장되지 않았으므로 SharePoint 항목 생성은 실행되지 않았습니다. 최신 건수 확정 전에는 이 오류를 고치거나 쓰기 Flow를 실행하지 않습니다.

1. 원본 읽기 전용 Flow 실행

  1. 저장 오류가 난 TAT_업체마스터_안전적재 편집 화면을 닫습니다. 변경 내용을 저장하거나 실행하지 않습니다.
  2. 원본 TAT_업체기본청구처_사전검사를 엽니다.
  3. Flow 트리에 SharePoint 항목 만들기·업데이트가 없는지 다시 확인합니다.
  4. Excel 업체계산서원천행조회가 갱신된 기존 개발용 파일의 tblTATMigration을 가리키는지 확인합니다.
  5. 원본 Flow를 수동으로 한 번 실행합니다.

2. 최신 집계값 확인

실행 기록에서 아래 출력의 숫자 또는 Boolean만 확인합니다.

  1. 업체계산서원천행수
  2. 업체계산서고유조합건수
  3. 업체계산서공란조합건수
  4. 업체계산서유효조합건수
  5. 업체고유건수
  6. 업체일대일후보건수
  7. 업체일대다예외건수
  8. 조합분류합계검증
  9. 업체분류합계검증
  10. 계산서마스터정상후보건수
  11. 계산서마스터미일치건수
  12. 계산서마스터중복건수
  13. 계산서마스터분류합계검증

전체 Flow도 성공이어야 합니다. 배열의 실제 업체명·계산서 업체명·ID는 열어보거나 전달하지 않습니다.

회신할 내용: 위 13개 출력값, 전체 Flow 성공 여부, SharePoint 쓰기 작업 없음 여부만 알려주세요. 최신 숫자를 확인한 뒤 TAT-04B의 고정 건수와 반복 참조를 새 기준으로 다시 작성합니다.
