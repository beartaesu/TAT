계산서업체마스터 연결을 완료했습니다. 이제 25행을 사람이 하나씩 확인하지 않고 Flow가 분석항목 불일치 건수만 계산합니다.

작업 위치: Power Automate → 내 흐름 → TAT_이관_시험조회 → 편집

1. 불일치 건수 변수 초기화

  1. 시험계산서업체ID확인 바로 아래에 변수 → 변수 초기화를 추가합니다.
  2. 작업 이름: 분석항목불일치건수초기화
  3. 변수 이름: var분석항목불일치건수
  4. 형식: 정수, 값: 0

2. 25행 반복 추가

  1. 분석항목불일치건수초기화 바로 아래에 제어 → 각각에 적용을 추가합니다.
  2. 작업 이름: 시험분석항목반복
  3. 이전 단계의 출력 선택은 식으로 body('시험접수행필터')를 입력합니다.
  4. 변수 증가를 안전하게 처리하려면 반복의 설정 → 동시성 제어를 클 때는 끈 상태로 두거나, 켤다면 병렬 처리 수를 1로 설정합니다.

3. 반복 안에 분석항목 조회 추가

  1. 시험분석항목반복 내부에 SharePoint → 2개 이상의 항목 가져오기를 추가합니다.
  2. 작업 이름: 반복_분석항목조회
  3. 사이트: 기존과 같은 TAT 사이트, 목록: 분석항목마스터, 상위 개수: 2
  4. 필터 쿼리의 식:
    concat('Title eq ''', replace(items('시험분석항목반복')?['분석항목'], '''', ''''''), '''')

4. 반복 안에 불일치 조건과 증가 추가

  1. 반복_분석항목조회 바로 아래에 제어 → 조건을 추가하고 이름을 반복_분석항목불일치조건으로 바꿉니다.
  2. 왼쪽 값의 식: length(body('반복_분석항목조회')?['value'])
  3. 연산자: 같지 않음, 오른쪽 값: 1
  4. Yes 내부에 변수 → 변수 증가를 추가하고 이름을 분석항목불일치건수증가로 바꿉니다.
  5. 이름: var분석항목불일치건수, 값: 1
  6. No는 비워 둡니다.

5. 반복 아래에 최종 건수 출력 추가

  1. 시험분석항목반복 전체 컨테이너 바로 아래에 데이터 작업 → 작성을 추가합니다. 반복 안이 아닙니다.
  2. 작업 이름: 시험분석항목불일치건수
  3. 입력의 식: variables('var분석항목불일치건수')
  4. Flow를 저장하고 같은 시험값으로 한 번 실행합니다.

알려줄 결과

  • 시험분석항목반복의 반복 횟수가 25인지
  • 시험분석항목불일치건수 입력·출력이 0인지
  • Flow 전체 성공 여부
분석항목명·마스터 행·실제 ID는 대화나 MYBOX 파일에 적지 말고, 반복 횟수와 불일치 건수만 알려주세요.

Power Apps 화면이나 컨트롤 트리에는 아무것도 추가하지 않습니다.
