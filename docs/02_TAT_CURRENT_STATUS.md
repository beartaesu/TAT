- 원인 판단: 신규 헤더를 만든 직후 `LookUp(Choices(...접수헤더연결), Id = var저장헤더.ID)`로 다시 찾는 방식이 새 헤더 Lookup 레코드를 반환하지 못해 `Blank()`가 저장된 것으로 본다.
- 저장소 교정안(미검증): 상세와 시료-항목 매핑 생성 분기의 `접수헤더연결`을 `Choices` 재조회 대신 `{ Id: var저장헤더.ID, Value: var저장헤더.제목 }` 직접 레코드로 저장하도록 전체 수식을 갱신했다.
- 별도 잔여 오류: `RemoveIf(접수항목상세, 접수헤더연결.Id = var저장헤더.ID)`에는 SharePoint Lookup 하위 `Id` 비교 위임 경고가 남아 있다. 기존 복사 열 5개에는 헤더 ID가 없으므로 이 경고는 해결되지 않는다.
- 제안/미적용: `접수항목상세`에 숫자 열 `접수헤더ID복사`를 추가·인덱싱하고 신규 저장·삭제 조건을 이 직접 숫자 열로 전환한다.
- 현재 재개 위치: 교정된 전체 수식의 Power Apps 문법을 먼저 확인한 뒤 신규 한 건으로 `접수헤더연결` 저장을 검증하고, 이어서 `접수헤더ID복사` 열 추가를 결정한다.
